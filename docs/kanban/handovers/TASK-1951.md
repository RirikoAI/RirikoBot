**Decisions & gotchas**
- Docusaurus rewrites any `url(/fonts/...)` inside `src/css` to a hashed `/assets/fonts/...` file, so the preload of `/fonts/*.woff2` would not match and the font would download twice. The @font-face rules therefore live in `website/static/fonts/fonts.css` (linked with `stylesheets`), next to the files; `custom.css` keeps tokens and rules. `webpackIgnore` in url() is not supported by this css-loader.
- `next/font/local` cannot set a `unicode-range` per file, so it serves only the latin files; the latin-ext files are declared in `globals.css` as families "Sour Gummy Ext" and "Libre Franklin Ext" appended in the font stacks.
- Docusaurus primary scale uses steps of -5, -7.5, -15 and +5, +7.5, +15 percent lightness (the ticket said about -10/-15/-30; the smaller steps match Docusaurus' own template and keep the light-mode hover link at 6.6:1). Dark-mode link hover uses the lighter shade so contrast does not drop. `--ifm-footer-link-hover-color` is pink-tint (the default primary hover would be 2:1 on the dark footer).
- Wizard: step icon fill and button hover moved to sakura-strong and sakura-hover, because white on #DF6E7E is 3.2:1.
- README banner files (`assets/readme/*`, `scripts/render-readme-banner.ts`) still name Karla: that is TASK-1952.
