## GROOMING · 2026-10-16T22:00:00Z · claude-opus-5-5 (coordinator)

**Report**: the maintainer's screenshot (2026-10-16, about 1500 px wide) shows bot messages in the demo drawn on top of each other after a few commands: "You used /play" overlaps "Now Playing", and so on.

**Root cause**:
- `.messages` (`website/src/components/DiscordDemo/styles.module.css`, about line 427) is a flex column with a fixed height (`position: absolute; inset: 0`).
- Its items have the default `flex-shrink: 1`. Normally `min-height: auto` stops a flex item from shrinking below its content.
- `.groupStart` (about line 493) sets `min-height: 44px`, which replaces `auto`. So once the content overflows, every message that starts a group shrinks to 44 px and its content overflows onto the next message.

**Fix**:
- Add `flex-shrink: 0` to `.message` and `.welcome`, and to any other direct child of `.messages` that has content. Leave `.spacer` as `flex: 1 1 auto`, so a short chat stays bottom-aligned.
- Check in a browser on the served build (port 3777, never 3000) with 10+ messages: no overlap, and the list scrolls inside the window.
