**Decisions & gotchas**
- `set` with `all` saves the four `*ChannelId` fields in one update; `off` saves `null` for the chosen fields only, and keeps ignored channels and ignore-bots. If every chosen log is already off it says so and saves nothing.
- `type` is required for `set` and `off` (no silent default to `all`). A missing or unknown type replies with the list of valid types.
- `set` accepts only text and announcement channels, found by mention or ID (cache, then fetch). The View Channel, Send Messages, Embed Links warning uses `channel.permissionsFor(guild.members.me)` and is skipped when the bot member is not cached; it never refuses.
- `ignore` toggles: an ID already in the list is removed without looking up the channel (so a deleted channel can be removed); a new one must exist. The 25-channel maximum comes back from the schema message. Its reply says it affects the message log only.
- `bots` without a value shows the current setting. Prefix accepts on/off/true/false/yes/no/enable/disable.
- Replies to slash are ephemeral and end with a hint to the dashboard **Logging** page.
- `website/src/data/commands.json` is generated by `pnpm docs:commands`; TASK-2025 regenerates it.
