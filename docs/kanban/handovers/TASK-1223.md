## PROGRESS · 2026-10-02T09:21:18Z · Claude Code (Opus 5.5) · REVIEW

**Files changed**
- `packages/database/scripts/generate-ddl.mjs`: renamed from `generate-sqlite-ddl.mjs`.
  - It writes both `SQLITE_SCHEMA_DDL` and the new `src/schema/pg/ddl.ts` (`PG_SCHEMA_DDL`, 93 tables), both with the BigInt-patched drizzle-kit export.
  - `"public".` is stripped, so the DDL builds in the `search_path`.
  - `package.json` `db:generate-ddl` points to it. The SQLite output is byte-identical.
- `packages/database/src/migrations/postgres-schema.ts`: `ensurePostgresSchema(client)`.
  - It runs on one pooled connection: `BEGIN`, `pg_advisory_xact_lock(1701, 1)`, a count of base tables in `current_schema()`, the DDL only if there are none (simple query protocol), then `COMMIT`.
  - It returns whether it created the schema. It is a no-op on SQLite.
  - Exported from `@ririko/database`.
- `apps/bot/src/main.ts`: calls it right after `createDatabaseClient`, before `runLegacyUpgrade`, because the migration needs the tables.
- `apps/web/src/lib/server/services.ts`: `getDatabase` calls it once per process.
- Tests:
  - `schema/pg/ddl.test.ts`: static parity of every `PgTable` and column, and no `"public".`.
  - `migrations/postgres-schema.test.ts`: the SQLite no-op, plus a Postgres-gated test where two clients race on an empty schema. Exactly one creates it, and the adventure and card-serial upgrades then succeed.
- `postgres.integration.test.ts` (adventure) now uses `ensurePostgresSchema` instead of spawning drizzle-kit.
- `docs/database.md` section 1: how empty databases are bootstrapped.

**Verification**
- verify_cmd passes: `db:generate-ddl` leaves no diff, 192 `packages/database` tests pass, typecheck and lint pass. `apps/web/src/lib/server` and `apps/bot/src` tests pass too, 674 tests.
- Against a local `postgres:16-alpine`:
  - The new bootstrap test passes.
  - The adventure suite: 4 of 5 pass. The 5th already failed before this change, and the FLAG is in `STORY-124.md`.

**Decisions & gotchas**
- It uses a raw pooled connection instead of `withTransaction`, so the multi-statement DDL goes over the simple query protocol.
