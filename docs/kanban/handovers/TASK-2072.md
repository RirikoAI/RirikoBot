## GROOMING · 2026-11-28T13:40:00Z · claude-large (coordinator)

**Approach**
1. Move the view logic into a new `apps/bot/src/commands/tcg/items-menu.ts`: load both inventories into one entry list (`{ source: 'tcg' | 'bag', category, name, rarity, quantity, level, wornBy, key }`), and pure builders for the embed and components (category select, item select, page buttons, action buttons). Pure builders keep it testable without Discord.
2. Rewrite `item.command.ts`: `createItemsCommand` (name `items`, TCG) and `createInventoryCommand` (name `inventory`, ECONOMY) share one handler. Read the action like the current execute does (slash `action`, else first prefix word), plus `ctx.invokedName` for the `use`/`consume` aliases. Keep `createCraftCommand` and `handleCraft` exported.
3. Remove `inventoryCommand` and `useCommand` from `createEconomyCommands` and their tests (move what still applies to the new tests).
4. `command-set.ts`: register the two commands in place of `createItemCommand`. `apps/bot/src/commands/tcg/index.ts` re-exports item.command.ts.
5. Data migration (same custom-migration path as TASK-2071): `UPDATE command_settings SET command_name = 'items' WHERE command_name = 'item'`.
6. Text and docs as listed.

**Relevant code**
- `item.command.ts` `handleInventory`: the current collector (120 s, invoker check, 3000-character list budget, wearer name lookup `loadWearerNames`) is the pattern to keep.
- Energy overview: `services.energyLifecycleService.getOrReconcileUserEnergy` and `.rules()` (see `energy.command.ts`). Dust: `services.enhancementService.getDustBalance(userId)` (used in `handleCraft`). Read only; do not edit enhancement-service.ts.
- `InventoryService.useItem` (`packages/services/src/economy/inventory.service.ts` ~242) handles ENERGY_RESTORE, XP_GRANT, CREDITS_GRANT, PROFILE_BG_TOKEN and generic. The profile background manager redeems the voucher itself, so a Use button on it would waste it.
- `ConsumableService.useItem` throws for HP and mana potions without a combatant, so they get no Use button.
- Discord: at most 5 component rows, 25 options per select menu, option labels up to 100 characters.

**Pitfalls**
- The registry throws on a duplicate alias, so `items` must stop being an alias of anything once it is a name.
- STORY-206 adds a `dismantle` entry to command-set.ts on another branch; keep your edit there small to ease the merge.

**Out of scope**
- The dismantle command (STORY-206) and enhancement-service.ts.
- /craft, /shop and /loadout behaviour.
