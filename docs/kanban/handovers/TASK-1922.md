## GROOMING · 2026-10-11T15:13:00Z · claude-opus-5-5 (coordinator)

**Approach**
1. Create `apps/cli/src/installer/checks.ts`. Each check takes plain values and a `deps` object (`fetch`, `discordApiBase`, `timeoutMs`, database factory) and returns `{ status, message, guideStep? }`.
2. Discord application check: `GET {base}/applications/@me` with `Authorization: Bot <token>`.
   - 401: "Discord rejected the bot token. Reset it (guide step 4) and paste the new one."
   - `id` differs from the Application ID entered: "This token belongs to another application."
   - Intents: map each privileged intent in `DEFAULT_GATEWAY_INTENTS` to its flag pair from `ApplicationFlags` (discord.js): GuildMembers to `GatewayGuildMembers` or `GatewayGuildMembersLimited`; MessageContent to `GatewayMessageContent` or `GatewayMessageContentLimited`. A bot in fewer than 100 servers gets only the Limited flags when the switch is on. Name each missing intent.
3. OAuth2 secret check: `POST {base}/oauth2/token`, body `grant_type=client_credentials&scope=identify`, Basic auth with `clientId:secret`. 200 passes, 401 is a wrong secret.
4. Database check: reuse the pattern of `databaseCheck` in `apps/cli/src/doctor/checks.ts` (`createDatabaseClient` with `connectionTimeoutMs`, `pingDatabase`, `close`). For SQLite do not create the file: check that the folder exists or can be created and is writable.
5. Optional providers: move the body of each branch in `testAiProviders`, `testStreamProviders` and `testImageProviders` into a check function; the three `test*` functions then loop over the checks and print, so their output and tests stay the same.
6. Replicate: `GET https://api.replicate.com/v1/account` with `Authorization: Bearer <token>`. The current `testImageProviders` only checks that the token is set; keep the CLI wording.

**Pitfalls**
- Tests must run offline (the suite has run offline since PR #658). Inject `fetch`; for the provider classes, stub their `checkHealth` or `globalThis.fetch` with `vi.stubGlobal`.
- YouTube without a key falls back to the public web page. The wizard asks for a key only when the YouTube switch is on, so the check must use the Data API path, not the fallback.
- Never put a token, key or full database URL in a message. Use `maskSecret`.
- The OpenAI check must honour `OPENAI_BASE_URL` (OpenRouter and other compatible services).
- `ai-configure.wizard.test.ts`, `image-configure.wizard.test.ts` and `stream-configure.wizard.test.ts` assert on printed lines. Keep the wording.

**Out of scope**
- Calling the checks from a page (TASK-1924).
- Changing `ririko doctor` (it keeps its presence-only Discord checks).
