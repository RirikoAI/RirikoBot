## GROOMING · 2026-10-12T16:25:21Z · claude-opus-5-5 (coordinator)

**Approach**
1. Inventory first: list every column in `packages/database/src/schema/sqlite/*.ts` that stores a Discord user id (names like `user_id`, `owner_id`, `target_id`, `moderator_id`, `actor_user_id`, `requested_by`, `host_id`, `winner`, `from_user`/`to_user`; check each file, the names vary). Grooming counted user-keyed columns in adventure, ai, economy, games, giveaways, identity, images, moderation, music, tcg, utilities, web and xp. Put the inventory in a typed constant (table, column, action) that the command and the guard test share.
2. CLI command in `apps/cli/src/commands/`, registered in `createProgram`, styled after `passkeys-reset` (it opens the database the same way and writes an audit entry).
3. Plan, print, then apply with `--yes` in a transaction.

**Pitfalls**
- The economy ledger is double-entry: deleting one side breaks balances. Tombstone the id instead.
- Trades and giveaways involve other users: tombstone.
- Never print or log the raw user id in the audit entry.

**Out of scope**
- A dashboard page or a bot command for self-service erasure.
