## 3. Key Findings & Decisions
- **YouTube SABR Mitigation**: Release versions of `youtube-plugin` (like 1.18.2) fail with `No supported audio streams available` due to YouTube SABR responses. Pinning the snapshot build `dev.lavalink.youtube:youtube-plugin:f45bbb7aebfcbc1c553769e04af6cd43afa8b7c3` with `ANDROID_VR` leading and remote cipher at `https://cipher.kikkia.dev/` provides rock-solid YouTube audio streaming.
- **ISRC Provider Priority**: LavaSrc uses `providers: ['ytsearch:"%ISRC%"', "ytsearch:%QUERY%", "scsearch:%QUERY%"]`, ensuring exact recording matching for Spotify tracks (e.g. Rainych's *Ride on Time* matching ISRC `JPP302100182`).
- **Startup Crash Prevention**: `applemusic`, `deezer`, `jiosaavn`, and `yandexmusic` require valid API keys/secrets; leaving them enabled with placeholders crashes Lavalink on startup. They are disabled by default.
- **Spotify 403 Forbidden**: `resolveArtistsInSearch: false` is strictly required to prevent Spotify Client Credentials apps from hitting the restricted `/v1/artists` endpoint.
