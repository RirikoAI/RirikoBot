## GROOMING · 2026-10-03T16:40:00Z · Claude Code (Opus 5.5)

**Source**: FLAG 2 and FLAG 3 of TASK-1251. Both are latent today.

1. `DungeonSeasonRepository.create` falls back to `randomUUID()` (36 characters) when no id is given, but `dungeon_seasons.id` is `varchar(32)` on Postgres. Callers always pass an id now, so it never fires.
2. `CommandSettingsRepository.listForGuild` orders by `asc(channelId)`. NULL (guild-wide) rows sort first on SQLite and last on Postgres, so the order differs per dialect.

**Fix**: generate a 32-character id (or reject a missing id) for seasons; use an explicit NULLS FIRST ordering (or order in code) for command settings. Add `describeDialects` tests for both.
