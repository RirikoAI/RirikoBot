**Repository API** (`StarboardRepository`, exported from `@ririko/database`; every method takes an optional `tx`)
- `getSettings(guildId)`: `StarboardSettings | null`.
- `upsertSettings(guildId, patch: StarboardSettingsPatch)`: creates or patches, other fields kept, returns the row.
- `findByMessage(messageId)` / `findByStarboardMessage(starboardMessageId)`: `StarboardPost | null`.
- `insertPost(data: NewStarboardPost)`: `Promise<boolean>`. Uses `onConflictDoNothing()` with no target, so it returns false for a duplicate `message_id` and also for a duplicate `starboard_message_id`; it does not throw on either.
- `updatePost(messageId, patch: StarboardPostPatch)`: returns the updated row or null when there is none; sets `updatedAt`. The patch cannot change `messageId`, `guildId` or `createdAt`.
- `deletePost(messageId)`: boolean.
- Also the BaseRepository contract over posts (id = original message id): `findById`, `exists`, `create` (throws on duplicate), `update` (throws DatabaseError if missing), `delete`, `count`.
