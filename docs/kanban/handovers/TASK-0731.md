## 2. Key Deliverables & Implemented Architecture

### 2.1. Dual-Dispatch Moderation Commands Suite (`createModerationCommands`)
Located in `apps/bot/src/commands/moderation/commands.ts` and `apps/bot/src/commands/moderation/index.ts`:
- **14 Moderation Commands with Slash & Prefix Parity**:
  - `/warn` (`!warn`): Applies dynamic warning escalation via `warningEscalationService.applyWarning(...)`, automatically calculating tier actions (e.g. timeout, kick, ban).
  - `/timeout` (`!timeout`, `!mute`): Restricts member interaction with duration parsing (`30s`, `10m`, `2h`, `1d`, `1w`), permission checks, and DM notification.
  - `/untimeout` (`!untimeout`, `!unmute`): Removes timeout penalty with audit case recording.
  - `/kick` (`!kick`): Kicks member from guild after hierarchy and permission validation.
  - `/softban` (`!softban`): Bans and instantly unbans user with message purge (1-7 days).
  - `/ban` (`!ban`): Permanently bans user from guild with configurable message deletion days.
  - `/unban` (`!unban`): Revokes user ban by user ID with audit trail.
  - `/purge` (`!purge`, `!clear`): Bulk message deletion with multi-filter support (`bots`, `humans`, `contains`, `user`, `pinned`) via `purgeService.purgeMessages(...)`.
  - `/lock` (`!lock`): Locks channel text permissions for `@everyone`.
  - `/unlock` (`!unlock`): Unlocks channel text permissions for `@everyone`.
  - `/nick` (`!nick`): Changes or resets target member guild nickname.
  - `/history` (`!history`, `!infractions`, `!cases`): Displays member disciplinary record, active warnings, and recent moderation cases via `disciplinaryHistoryService`.
  - `/note` (`!note`, `!staffnote`): Adds or lists staff notes on target user via `disciplinaryHistoryService`.
  - `/automod` (`!automod`): Manages and inspects guild AutoMod rule configs (view status, enable/disable rules).
- **Duration Parsing Utilities**:
  - `parseDurationToSeconds(input: string)`: Supports seconds, minutes, hours, days, weeks; clamps to Discord's 28-day API maximum.
  - `formatDurationSeconds(seconds: number)`: Human-readable duration formatting.
- **BotServices Integration**:
  - `apps/bot/src/services.ts`: Wired all 9 moderation repositories and domain services:
    - `moderationRepo`
    - `permissionService`
    - `moderationActionService`
    - `moderationLogService`
    - `disciplinaryHistoryService`
    - `warningEscalationService`
    - `purgeService`
    - `autoModService`
    - `antiRaidService`
