## 1. Summary of Completed Work
Implemented the high-performance, event-driven audio queue state machine in `packages/music/src/queue`:
1. **Audio Queue State Machine (`GuildQueue`)**:
   - Manages track FIFO queue with capacity checks (`maxQueueSize: 1000`).
   - Maintains a playback history stack (`maxHistorySize: 100`) for the `/back` replay command.
   - Reactive event architecture using typed `EventEmitter` emitting: `trackStart`, `trackEnd`, `queueEnd`, `stateChange`, `volumeChange`, `filterChange`, `loopChange`, `trackAdded`, `tracksAdded`, `trackRemoved`, `queueCleared`, `queueShuffled`, and `error`.
   - Supports Fisher-Yates array shuffling, track reordering (`moveTrack`), track removal by index, and playback position tracking (`seek`).
2. **Loop Modes**:
   - `OFF`: Normal FIFO playback; tracks are pushed to history when finished.
   - `TRACK`: Repeating current track; replayed on `onTrackFinished` without altering queue order.
   - `QUEUE`: Loop entire queue; finished tracks are appended to the back of the queue.
   - Manual `skip()` advances to next track and bypasses single-track repeat to prevent infinite loops.
3. **Volume Clamping & Gain Calculation**:
   - Strictly clamps volume between `0%` and `150%` (`clampVolume`) to safeguard user hearing and prevent audio clipping.
   - Linear gain multiplier calculation (`volumeToGain`) for `@discordjs/voice` AudioResources.
4. **Audio Filter Presets & FFmpeg Arguments**:
   - Filter presets: `bassboost` (+10dB with dynaudnorm), `bassboost_high` (+20dB), `nightcore` (+25% pitch, 1.06x tempo), `vaporwave` (0.8x speed), `8d` (binaural rotational panning), `treble` (+5dB), `pop`, `soft`, `karaoke`, and `normal`.
   - Dynamic compilation into FFmpeg `-af` argument arrays (`buildFilterArgs`).
5. **Autoplay Engine (`AutoplayEngine`)**:
   - Queries `ExtractorPipeline` for related songs based on the finished track's artist and title.
   - Deduplicates recommendations against recent playback history and upcoming queue tracks.
   - Automatically enqueues and plays recommended tracks when the queue runs dry if `autoplay` is enabled.
6. **Queue Registry (`QueueManager`)**:
   - Centralized registry managing `GuildQueue` instances mapped by `guildId` with lifecycle cleanup (`destroyAll`, `delete`).

## 3. Key Design Decisions & Gotchas
- **Manual Skip vs Loop TRACK**: In `skip()`, single-track loop mode is bypassed so a manual skip command will advance to the next track rather than replaying the same song indefinitely.
- **Deduplication in Autoplay**: `AutoplayEngine` maintains sets of normalized URLs and lowercase titles across seed, history, and active queue to prevent repeating recently played tracks.
- **Options Initialization**: In strict TypeScript mode with `exactOptionalPropertyTypes`, options are resolved against defaults to guarantee non-optional numeric values.
