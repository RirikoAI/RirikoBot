## 2. Plan
1. **Canvas-free subpath** `@ririko/services/dungeon-scaling` (add to `packages/services/package.json` exports, like `./owner`) exporting `scaling-engine` and `boss-definition` only.
2. **Shared validation**: element enum for `theme_element` (reuse the TCG element list; allow `ALL`), affix list validated against known affix words, `scalingModel` enum, `seasonCurveSchema` for params, `bossDefinitionSchema` for definitions. Dates: `endsAt > startsAt`.
3. **Audited service** `DungeonSeasonAdminService` in `@ririko/services/owner`: list/create/update seasons, set active (deactivates other non-tutorial seasons in one transaction), update boss definition (enrage, `wardLayers`, `maxTurns`, signature drop). Audit actions `owner.dungeon_season.*`, `owner.dungeon_boss.update`, `guildId: null`.
4. **Fix active-season selection**: `findActiveSeason` also requires `starts_at <= now` and (`ends_at` null or `> now`).
5. **Web** `apps/web/src/app/owner/dungeon/` (copy the `owner/shop` CRUD layout: list page, `new/`, `[seasonId]/`, form component, `runOwnerAction`, `revalidatePath('/owner/dungeon', 'layout')`). Owner nav entry "Dungeon".
6. **Curve visualizer**: compute HP/ATK/DEF for floors 1-N on the server with `new ScalingEngine(toScalingConfig(model, parseSeasonCurve(params)))`, pass points to a hand-written SVG client chart modelled on `apps/web/src/components/usage-chart.tsx` + `lib/chart-format.ts`. Mark boss floors (every 5th mini, 10th major). Note on the page that HYBRID ignores parameters.
7. Update `docs/waifu-tcg.md` and `docs/dashboard.md`.
