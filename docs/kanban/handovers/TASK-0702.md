## 2. Key Deliverables & Implemented Architecture

### 2.1. Sequential Case Audit Logger (`ModerationLogService`)
Implemented in `packages/services/src/moderation/moderation-log.service.ts`:
- **Rich Embed Constructor (`buildCaseEmbed`)**:
  - Color-coded by action type (`BAN`/`SOFTBAN`: Red, `KICK`: Orange, `TIMEOUT`/`WARN`: Yellow, `UNBAN`/`UNTIMEOUT`: Green, `LOCK`/`UNLOCK`/`NICK`: Blurple).
  - Embed fields: Target User with mention and tag, Moderator with mention and tag, Reason, Duration (if applicable), and Action Metadata (e.g. purged message days, nickname modifications).
  - Standardized Case ID and timestamp footer.
- **Log Channel Dispatcher (`logCase`)**:
  - Looks up `guild_settings.logChannelId`.
  - Validates channel existence, text capabilities, and bot permissions (`ViewChannel`, `SendMessages`, `EmbedLinks`).
  - Fetches user details and posts the embed.
- **Reactive EventBus Listener (`startListening`)**:
  - Automatically listens to `moderation:caseCreated` events and asynchronously routes log embeds without blocking command execution.

### 2.2. Disciplinary History & Staff Notes Manager (`DisciplinaryHistoryService`)
Implemented in `packages/services/src/moderation/disciplinary-history.service.ts`:
- **User Disciplinary Summary (`getSummary`)**:
  - Aggregates active warnings, complete case history, and staff notes.
  - Computes counts: `activeWarningCount`, `totalWarningCount`, `timeoutCount`, `kickCount`, `banCount`, and `totalInfractions`.
  - Calculates dynamic risk level:
    - `LOW`: Clean or minimal minor infractions.
    - `MEDIUM`: 2 active warnings or 1 timeout.
    - `HIGH`: 3+ active warnings, 2+ timeouts, or kick history.
    - `CRITICAL`: Prior bans, 5+ active warnings, or repeat high-volume offender.
- **Visual Disciplinary Profile (`buildHistoryEmbed`)**:
  - Formats a comprehensive embed with user avatar, risk level color, breakdown metrics, recent cases (up to 5), and recent staff notes (up to 3).
- **Persistent Staff Notes CRUD**:
  - `addNote(guildId, targetUserId, authorUserId, content)`
  - `getNotes(guildId, targetUserId)`
  - `deleteNote(id)`
