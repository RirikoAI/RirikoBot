## 2. Technical Scope & Implementation Delivered
1. **`WaifuAssetRepository` (`packages/database/src/repositories/waifu-asset.repository.ts`)**:
   - Dual-dialect Drizzle repository supporting SQLite (`better-sqlite3`) and PostgreSQL (`pg`).
   - Implements source management (`upsertSource`, `findSourceById`, `listActiveSources`).
   - Implements asset queries and mutations:
     - `create(data: NewWaifuAsset)`
     - `findById(id: string)`
     - `findByImageHash(imageHash: string)`
     - `findBySourceImageId(sourceId: string, sourceImageId: string)`
     - `findAssetsByCharacter(name: string)`
     - `findActiveAssets(limit: number, offset: number)`
     - `count(activeOnly?: boolean)`
     - `markDeletedByRequest(assetId: string)`
2. **`ImageValidator` (`packages/services/src/waifu-tcg/ingestion/image-validator.ts`)**:
   - Binary header inspection for magic bytes (PNG, JPEG, WebP).
   - Dimension validation: Minimum 400x600 resolution.
   - Aspect ratio validation: Tolerates standard portrait ratios (0.5 to 0.85).
   - SHA-256 content digest computation.
3. **`WaifuImClient` (`packages/services/src/waifu-tcg/ingestion/waifu-im.client.ts`)**:
   - SFW-enforced queries to `api.waifu.im/search`.
   - Exponential backoff retry logic for HTTP 429 and network errors.
   - Tag, character name, and anime title extraction heuristics.
4. **Canonical Seed Fixtures (`packages/services/src/waifu-tcg/ingestion/seed-assets.ts`)**:
   - 25 canonical waifu assets covering all 7 elements (FIRE, ICE, EARTH, LIGHTNING, WATER, LIGHT, SHADOW).
   - Mock PNG buffer generator with variable seed embedding (`tEXt` chunk) for deterministic testing.
5. **`IngestionService` (`packages/services/src/waifu-tcg/ingestion/ingestion-service.ts`)**:
   - Orchestrates downloading, binary validation, SHA-256 deduplication, and asset persistence.

## 4. Architectural Decisions & Gotchas
- **ArrayBuffer Slicing in Mock Downloads**:
  - In Node.js, `Buffer.concat` may allocate from an internal pool where `buffer.byteOffset > 0`. In test mocks, always use `Uint8Array.from(buf).buffer` when mocking `res.arrayBuffer()` to prevent offset alignment issues.
- **Unique Mock PNG Digests**:
  - Minimal PNGs with identical dimensions produce identical SHA-256 digests. Added optional `seed` parameter to write a valid `tEXt` chunk, guaranteeing unique hashes per character definition during canonical seeding.
