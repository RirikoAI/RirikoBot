## 3. Gotchas & Architecture Decisions
- To prevent database deadlocks under high concurrency where user A transfers to user B while user B simultaneously transfers to user A, accounts are acquired in deterministic lexicographical order of user IDs.
- Interest awards respect bank capacity limits: if interest would overflow bank capacity, it is safely truncated to the exact remaining headroom.
