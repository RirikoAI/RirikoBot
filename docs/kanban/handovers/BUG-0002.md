## 1. Summary of Bug & Root Cause

### Symptoms
When a user requested Spotify playback for Rainych's cover of *RIDE ON TIME* (`https://open.spotify.com/track/7a6Gj71tooMRmxcZwdGNnh`), a 1989 British/Italian dance track (*Ride on Time* by Black Box) was streamed instead.

### Root Causes
1. **Weak Artist Weighting & Missing Hard Gate in `PrecisionTrackMatcher`**:
   - The composite scoring formula was: `durationScore * 0.35 + titleScore * 0.45 + artistScore * 0.20`.
   - Any track with the same title (*Ride on Time*) and similar duration (~280s) scored **0.80**, easily surpassing the `0.65` confidence threshold even when the artist had a **0% match**.
   - The topic channel bonus was also applied unconditionally without verifying that at least one artist keyword matched.
2. **Unconstrained Bare Title Fallback in `YouTubeAdapter` (Tier 6)**:
   - When direct YouTube streaming failed or hit bot/SABR checks on Windows, Tier 6 executed an unconstrained search on SoundCloud using bare `cleanTitle` (`"RIDE ON TIME"`).
   - The top hit on SoundCloud for `"RIDE ON TIME"` was Black Box's Eurodance track.
   - Tier 6 streamed `scResults[0]` without checking artist, duration, or running through the matching engine.

## 2. Key Code Changes

1. **Hard Artist Gate in [`packages/music/src/extractors/track-matcher.ts`](file:///Z:/Projects/ririko-v2-2026/packages/music/src/extractors/track-matcher.ts)**:
   - Added hard artist disqualification: If target artist is known and candidate artist score is `< 0.25`, the candidate immediately receives a score of `0`.
   - Fixed `topicBonus` to only apply if `matchedArtists > 0`.
   - Rebalanced composite weights: `artistScore * 0.40 + titleScore * 0.35 + durationScore * 0.25`.
2. **Eliminated Blind Fallback in [`packages/music/src/extractors/youtube.adapter.ts`](file:///Z:/Projects/ririko-v2-2026/packages/music/src/extractors/youtube.adapter.ts)**:
   - Restricted external query generation to never search bare `cleanTitle` when an author is known.
   - Wired `PrecisionTrackMatcher` into Tier 6 (SoundCloud) and Tier 7 (Deezer) inside `resolveVideo`. Candidates are strictly filtered and rejected if they fail confidence scoring ($\ge 0.70$).
3. **Streamlined Pipeline Bridging in [`packages/music/src/extractors/pipeline.ts`](file:///Z:/Projects/ririko-v2-2026/packages/music/src/extractors/pipeline.ts)**:
   - Raised confidence threshold to `0.70` for YouTube and `0.75` for SoundCloud.
4. **Automated Regression Tests in [`packages/music/src/extractors/track-matcher.test.ts`](file:///Z:/Projects/ririko-v2-2026/packages/music/src/extractors/track-matcher.test.ts)**:
   - Added test verifying that Black Box's *Ride on Time* (280s) scores `0` against Rainych's *RIDE ON TIME* (276s).
   - Added test verifying candidate lists containing cross-artist title collisions return `null` when no legitimate match exists.
5. **Monorepo Build Synchronization**:
   - Recompiled `@ririko/music` (`pnpm --filter @ririko/music build`) to ensure the running bot (`pnpm dev:bot`) imports updated code from `./dist`.
