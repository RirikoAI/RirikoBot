## 1. Summary of Work Accomplished
- **Centralized Permission Middleware ([`packages/discord/src/middleware/permissions.ts`](file:///z:/Projects/ririko-v2-2026/packages/discord/src/middleware/permissions.ts))**:
  - Implemented `createPermissionMiddleware(options)`.
  - Resolves Discord permission bigints to human-readable strings via `resolvePermissionNames()` using `PermissionsBitField`.
  - Enforces:
    - Guild-only restriction (`metadata.isGuildOnly`), throwing `CommandGuildOnlyError`.
    - Bot developer / owner-only restriction (`metadata.isOwnerOnly`), throwing `CommandPermissionError`.
    - Member Discord bitfields (`metadata.userPermissions`), evaluating `ctx.member.permissions.has()`.
    - Bot client Discord bitfields (`metadata.botPermissions`), evaluating `ctx.guild.members.me.permissions.has()`.
- **Maintenance Mode Middleware ([`packages/discord/src/middleware/maintenance.ts`](file:///z:/Projects/ririko-v2-2026/packages/discord/src/middleware/maintenance.ts))**:
  - Implemented `createMaintenanceMiddleware(options)`.
  - Evaluates maintenance state via `isMaintenanceEnabled()`.
  - Supports developer bypass using `ownerIds` or custom `isOwner()` predicate.
  - Rejects regular user invocations with `CommandMaintenanceError`.
- **Module Toggle Middleware ([`packages/discord/src/middleware/modules.ts`](file:///z:/Projects/ririko-v2-2026/packages/discord/src/middleware/modules.ts))**:
  - Implemented `createModuleToggleMiddleware(options)`.
  - Evaluates whether command's `metadata.category` is enabled in `ctx.guildId` via `isModuleEnabled(guildId, category)`.
  - Supports configurable exempt categories (e.g. `GENERAL`).
  - Rejects disabled category requests with `CommandDisabledError`.
- **Scoped Cooldown Middleware ([`packages/discord/src/middleware/cooldown.ts`](file:///z:/Projects/ririko-v2-2026/packages/discord/src/middleware/cooldown.ts))**:
  - Implemented `createCooldownMiddleware(options)` supporting user, channel, and guild scoping.
  - Enforces `metadata.cooldownSeconds`, tracking expiration timestamps in a memory cache.
  - Automatically sweeps expired entries to prevent memory accumulation.
  - Supports custom bypass evaluator.
  - Rejects premature calls with `CommandCooldownError` with exact `retryAfterSeconds`.
- **Sliding-Window Rate Limit Middleware ([`packages/discord/src/middleware/ratelimit.ts`](file:///z:/Projects/ririko-v2-2026/packages/discord/src/middleware/ratelimit.ts))**:
  - Implemented `createRateLimitMiddleware(options)` using a sliding-window token algorithm.
  - Enforces `metadata.rateLimit: { max, windowSeconds }`.
  - Throws `CommandRateLimitError` calculating exact time-to-reset.
- **Automated Test Coverage ([`packages/discord/src/middleware/middlewares.test.ts`](file:///z:/Projects/ririko-v2-2026/packages/discord/src/middleware/middlewares.test.ts))**:
