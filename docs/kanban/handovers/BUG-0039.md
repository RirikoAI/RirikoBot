## GROOMING · 2026-10-09T12:37:08Z · claude-opus-5-5 (coordinator)

**Approach**
1. In `handleInventory` (`apps/bot/src/commands/tcg/item.command.ts`), extend `loadItems` so it also builds a map from card ID to card name for worn gear. Collect the distinct `inv.equippedToCardId` values of rows with `state === 'EQUIPPED'`. For each one, call `services.waifuCardRepo.findUserCardById(id)` and then `services.waifuCardRepo.findById(userCard.cardId)` to get the name. Return the map with the items so the embed builder stays pure.
2. In `buildInvEmbed`, add the ID to each list line, for example ``ID: `<inv.id>` ``. Change the state tag to `` `[EQUIPPED: <SLOT> on <card name>]` ``. Use the card ID when the name is missing.
3. Add the ID to the Selected Item line.
4. In `info.command.ts`, update the gear guide line "Check worn gear: `/item action:inventory` tags it `[EQUIPPED: <SLOT>]`" so it describes the new tag and says the inventory shows item IDs for the by-ID commands.
5. Extend the tests in `item.command.test.ts` (inventory cases near line 245) and update the matching expectations in `info.command.test.ts`.

**Relevant code** (from CodeGraph during grooming)
- `apps/bot/src/commands/tcg/item.command.ts:153` `loadItems`: loads inventory rows and item definitions. Filters reload it, so the card-name lookup belongs here.
- `apps/bot/src/commands/tcg/item.command.ts:197` `stateTag`: the current `[EQUIPPED: ${inv.slot}]` tag.
- `apps/bot/src/commands/tcg/item.command.ts:193`: the list shows only the first 15 items (`slice(0, 15)`).
- `packages/database/src/repositories/waifu-card.repository.ts:366` `findUserCardById` and `:41` `findById`: card instance and card definition (name).
- `apps/bot/src/commands/tcg/info.command.ts:126`: the gear guide line to update.
- `apps/bot/src/commands/tcg/card.command.ts:148-149`: the by-ID usage that players cannot follow today.

**Pitfalls**
- Embed descriptions cap at 4096 characters. Fifteen lines with an ID and a card name add length. Check the longest realistic case in a test, or keep the ID tag short.
- Equipped rows can point at a card the user no longer owns (stranded gear; see CHORE-0602). The lookup must not throw: fall back to the card ID.
- Look up each distinct card once per load, not once per line or per render.

**Out of scope**
- A Craft & Equip button (STORY-162, abandoned).
- Any change to `/card` commands, `LoadoutService` or repositories. Use the existing repository methods.
