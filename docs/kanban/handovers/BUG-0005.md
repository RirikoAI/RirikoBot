## 1. Summary of Changes

### The Problems
1. **Duplicate Tool Execution**:
   In `AiChatController`, when a model streams a tool call, `stream(request)` emits tool calls in the final token but produces empty text content (`token.text === ''`).
   The controller checked `if (!accumulatedContent)`, erroneously assuming streaming had failed, and immediately invoked `generate(chatRequest)` a second time.
   `generate()` emitted the identical tool call, causing `accumulatedToolCalls` to contain duplicates. `executeBatch` then executed every tool twice (e.g. coin flip executed twice, balance checked twice, reminders scheduled twice).

2. **Raw Ugly JSON Output**:
   Instead of feeding tool execution outputs back to the LLM to synthesize a natural language, in-character response, both `AiChatController` and `/ai chat` slash commands merely dumped `JSON.stringify(tr.result)` into Discord messages:
   ```
   [get_current_time]: {"iso":"2026-09-17T08:44:53.053Z","formatted":"Thursday, September 17, 2026 at 8:44:53 AM UTC","timezone":"UTC","utcOffset":"GMT+0"}
   ```

### The Solutions
1. **Deduplication & Stream Liveness Tracking**:
   - In `AiChatController`, introduced `streamSucceeded = true` when streaming produces either content OR tool calls.
   - `generate()` is only called as a fallback if streaming threw an error or produced neither content nor tool calls.
   - Added tool call deduplication by unique key (`id` or `name:args`).
2. **Follow-up LLM Synthesis Turn**:
   - Once tools execute, the results are passed back to the model as `role: 'tool'` messages with `tools: undefined` (to prevent infinite tool loops).
   - The LLM synthesizes a polite, friendly in-character conversational response incorporating the tool outputs (e.g. "The current time in Malaysia is 4:50 PM (GMT+8) on Thursday, September 17, 2026! 🕒").
3. **Clean Fallback Formatter (`formatToolResultFallback`)**:
   - Added `packages/ai/src/tools/formatter.ts` and exported from `@ririko/ai`.
   - If the second LLM synthesis turn fails or is unavailable, the output gracefully formats into clean markdown (e.g. `🕒 **Current Time**: ...`, `🪙 **Coin Flip**: ...`, `🎬 **Anime**: ...`, `💰 **Balance**: ...`, `⏰ **Reminder Set**: ...`) and strips HTML tags from external APIs like AniList, never showing raw JSON to users.

## 3. Key Decisions & Gotchas

- In follow-up synthesis requests, `tools: undefined` is explicitly passed to guarantee the LLM terminates the turn and produces conversational text rather than re-requesting the same or another tool.
