- a hero, features, statistics and an FAQ;
- a Discord-styled command demo (`discord.js`, `discord.css`);
- a command list by category (`categories.php`).

**Approach**
1. Rebuild the sections as React components in `website/src/pages/index.tsx`.
2. Drop the PHP and the Bootstrap CDN. Keep the Discord-styled demo only if it can be done in CSS.
3. For the commands, a script imports the bot command definitions (`createCommandControllers`, which needs no Discord connection). It writes `website/static/commands.json` or a TS module. A page renders it with category filters.

**Pitfall**: importing the bot's command set may pull in heavy modules (canvas, database). If it does, read the metadata only, or move the metadata export into a light module.
