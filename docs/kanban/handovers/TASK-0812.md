## 2. Key Deliverables & Implemented Architecture

### 2.1. Dual-Dispatch Stream Commands Suite
Implemented in `apps/bot/src/commands/streams/stream.command.ts`:
- **`/stream`**:
  - `subscribe`: Subscribes current guild to streamer alerts on Twitch, YouTube Live, or TikTok Live, with platform autodetection, role mention options, and custom alert templates. Requires `ManageGuild` permission.
  - `unsubscribe`: Removes stream alerts subscription for the specified streamer. Requires `ManageGuild` permission.
  - `list`: Embed listing all monitored streamers in the server with real-time status (`🟢 LIVE` or `⚫ Offline`).
  - `channel`: Configures default announcement channel for all stream alerts in the guild.
- **Legacy Prefix Command Parity**:
  - `!subscribe <streamer> [platform]`
  - `!unsubscribe <streamer>`
  - `!setup-twitch <channel>`
  - `!twitch-status` / `!stream-status`
- Validated via unit/integration tests in `apps/bot/src/commands/streams/__tests__/commands.test.ts`.

### 2.2. Dual-Dispatch Free Games Command Suite
Implemented in `apps/bot/src/commands/streams/free-games.command.ts`:
- **`/freegames`**:
  - `show` (default): Interactive embeds displaying currently active 100% free promotional games from Epic Games Store and Steam with interactive direct store link buttons, formatted markdown descriptions, original strike-through prices, and relative timestamp countdowns (`<t:end_time:R>`).
  - `setchannel`: Sets server-wide announcement channel for automatic free game alerts. Requires `ManageGuild` permission.
  - `remove`: Disables and removes automatic free game alert channel configuration. Requires `ManageGuild` permission.
- **Legacy Prefix Command Parity**:
  - `!freegames`
  - `!freegames show`
  - `!freegames setchannel #channel`
  - `!freegames remove`
- Validated via unit/integration tests in `apps/bot/src/commands/streams/__tests__/commands.test.ts`.
