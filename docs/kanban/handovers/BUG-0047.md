3. Rewrite `assets/installer/wizard.css` toward `.local/installer-1x/assets/css/bd-wizard.css`: Karla, the sizes in the acceptance, Bootstrap 4 defaults the 1.x page inherited (body line-height 1.5, `.btn` padding 6px 12px, 4px radius, `.card-body` 20px padding). - `apps/cli/src/installer/steps.ts`: pages, `note`, `guides`, `switches`, `appliesWhen`.

## PROGRESS · 2026-10-15T12:39:29Z · ticket-worker-sonnet (sonnet) · REVIEW

**What changed**
- `steps.ts`: the page-level `note` (one Note box above the fields) is replaced by `blocks: NoteBlock[]`. A block holds the numbered points, the field it follows (`after`), an optional `when` (switch and/or choice) and its guide buttons, each with its own `when`. `page.guides` stays as the list of guides a page uses (a test checks every one is placed in a block). The "Leave a feature off..." note was dropped (not in 1.x).
- `render.ts`: per group the order is switch, its fields, the note, then the guide buttons (1.x order). A switch renders just before the first field of its feature. Gated blocks and buttons carry `data-gate`; `conditionalCss()` generates the `:has()` rules for them next to the field rules (hidden by default; a `@supports not selector(:has(*))` fallback shows all). Labels are `Label:` in a 16px label like the 1.x `p.text-sm`. The switch description text, the guide card title and the Note box are gone; the guide button (the `<summary>`) opens its card directly below it. A guide used by two features (Gemini, for chat and for images) is placed twice, the second copy with ids `guide-gemini-2...`. The brand header has the 1.x intro line.
- `assets/installer/wizard.css`: rewritten against `bd-wizard.css` and the Bootstrap 4 defaults (see the page list). Colors are the 2.0 palette. No box, card, badge or border beyond the 1.x ones (tab, content area, button, guide card, bottom border of the action row).
- Karla: self-hosted. `assets/installer/fonts/karla-latin.woff2` and `karla-latin-ext.woff2` (one variable file per subset, weights 400 and 700, from fonts.gstatic.com as listed by the official Google Fonts CSS for Karla v33) and `OFL.txt` (from github.com/googlefonts/karla). `server.ts` serves `/assets/fonts/*` (`font/woff2`, `.txt`). CSP is unchanged (`default-src 'self'` covers the font), Referrer-Policy is still `same-origin`, no JavaScript.
- Tests: `render.test.ts` gained "order of the 1.x installer" (heading before fields; note and guide buttons after the fields and after their group's last field; switch before fields; gated guide buttons inside their gated block, with the generated CSS for them; no `feature` boxes). `steps.test.ts`: every guide of a page is placed in a block. `server.test.ts`: font, license, no external host in the stylesheet.
- Files outside `context.files` that I changed: `server.ts` (serve the font folder) and `assets/installer/fonts/` (new); both added to `context.files`.
