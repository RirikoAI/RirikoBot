# TASK-1052 Handover: WaifuGuilds Factions, Multi-Asset Achievement Reward Dispatch, TCG Admin & Dual-Dispatch Commands Suite

## 1. Summary of Changes
- **Dual-Dialect Repositories (`packages/database`)**:
  - `WaifuGuildRepository` (`packages/database/src/repositories/waifu-guild.repository.ts`):
    - Full CRUD for `waifu_guilds` and `waifu_guild_members` tables across SQLite and PostgreSQL.
    - Manages member rosters, roles (`LEADER`, `OFFICER`, `MEMBER`), contributions, bank balances (`balance`), level, and XP.
    - Includes `findGuildByUserId`, `addMember`, `removeMember`, `updateMemberRole`, `depositToBank`, and `listTopGuilds`.
  - `AchievementRepository` (`packages/database/src/repositories/achievement.repository.ts`):
    - Full CRUD for `game_achievements` and `user_achievements` tables across SQLite and PostgreSQL.
    - Manages progress tracking, atomic unlocking, and reward claiming with `updateProgressAndCheckUnlock`, `claimAchievement`, and `listUserAchievements`.
  - `TcgConfigRepository` (`packages/database/src/repositories/tcg-config.repository.ts`):
    - Key-value JSON config repository for `tcg_system_configs` table with typed `getConfig`, `setConfig`, and `getAllConfigs`.
  - Exported all repositories via `packages/database/src/repositories/index.ts`.
- **Services Layer (`packages/services/src/waifu-tcg`)**:
  - `WaifuGuildService` (`guild/waifu-guild.service.ts`):
    - Guild creation with 5,000 Credits fee deducted via `EconomyRepository`.
    - Dynamic capacity calculation: $10 + \text{Level} \times 2$.
    - Leveling progression math: $\lfloor 1000 \times \text{Level}^{1.5} \rfloor$.
    - Atomic credit deposits into Guild Bank with member contribution tracking.
    - Roster management: Officer promotion/demotion, member kick, leave, and disbanding with role-based authorization.
  - `AchievementService` (`achievements/achievement-service.ts` & `seeds.ts`):
    - Canonical 9 seed achievements across 6 tracks (Gacha, Combat, Leveling, Economy, Collection, Social) and 5 tiers (Bronze, Silver, Gold, Platinum, Diamond).
    - Event-driven progress tracking (`onEvent`) and atomic unlocking.
    - 7-Asset multi-reward dispatch engine:
      1. Account EXP (`UserProfileRepository.addExp`)
      2. Credits (`EconomyRepository.transferBalance` / `updateBalance`)
      3. Collectible Cards (`WaifuCardRepository.createUserCard`)
      4. Equipment Weapons (`InventoryRepository.create`)
      5. Equipment Accessories (`InventoryRepository.create`)
      6. Consumables (`ConsumablesInventoryRepository.addItem`)
      7. Titles / Badges (`UserProfileRepository.updateBadges`)
  - `TcgConfigService` (`admin/tcg-config.service.ts`):
    - Dynamic system configuration management with Zod schema validation:
      - Energy configuration (`baseRegenMinutes`, `maxEnergy`, `energyPerRegen`)
      - Dungeon configuration (`globalDropMultiplier`, `bonusExpMultiplier`)
      - Market configuration (`taxRate`, `listingDurationDays`)
      - Role configuration (`adminRoleIds`)
    - Role and permission authorization checking (`isAuthorized`).
  - Exported all services via `packages/services/src/waifu-tcg/index.ts`.

## 3. Decisions & Gotchas
- Member roles in Discord.js v14: `member.roles` is a `GuildMemberRoleManager`; role IDs are safely extracted via `Array.from((member.roles as any).cache?.keys?.() ?? [])`.
- `ICommandOptionsResolver`: Subcommands and roles do not have `getRole()` in custom context wrappers; roles are parsed via `getString('role')` stripping snowflake format characters (`<@&...>`).
- Repository normalization: `BigInt` returned by PostgreSQL for currency and balances is converted to `number` in `WaifuGuildRepository` and `AchievementRepository`.
- Database schema typing: `NewWaifuGuild` allows optional `id` to leverage Drizzle's auto-generated UUID primary keys.
