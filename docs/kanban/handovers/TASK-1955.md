**Root cause of the clip (found in review)**
- `.chat` is a grid with rows only, so its implicit column is `auto` and grows to the widest unbreakable content. With Android text scaling (reproduced with `text-size-adjust: 140%` at 390 px) the column became 398 px inside a 349 px window, and `.window` clips it. With `minmax(0, 1fr)` the overhang is 0.
