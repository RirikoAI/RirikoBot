## GROOMING · 2026-10-12T16:25:21Z · claude-opus-5-5 (coordinator)

**Approach**
1. Schema: add `userConsents` to `packages/database/src/schema/sqlite/identity.ts` and `pg/identity.ts` (same shape as `users`: `text` ids, `timestamp_ms` on SQLite, `timestamp` with time zone on PostgreSQL as the neighbouring tables do). Export the types from `schema/types/index.ts`. Run `pnpm db:generate`, review both SQL files, commit the migration, the embedded modules and the DDL files it produces.
2. Repository `UserConsentRepository` next to `user.repository.ts`, dual-dialect like `CommandSettingsRepository` (constructor takes `DatabaseClient`). Upsert with `onConflictDoUpdate` on the composite key.
3. `packages/services/src/privacy/consent.service.ts` (new folder, export from `packages/services/src/index.ts`): versions as exported constants, `hasAccepted`, `accept`, `withdraw`, an in-memory `Set` of `userId:kind:version` that `withdraw` clears.
4. Notice: a middleware is the natural place, but middlewares run before the command and the notice must come after it. Wrap `next()`: `await next(); await maybeNotify(ctx)`. Put the generic part (`createNoticeMiddleware({ shouldNotify, notify })`) in `packages/discord/src/middleware/` and the wording and service calls in the bot. Add it last in `createCommandRouter` so blocked commands (maintenance, permissions, cooldown) do not count as an interaction.
5. Delivery: interactions use `ctx.followUp({ content, flags: MessageFlags.Ephemeral })` (the command has replied by then; if it has neither replied nor deferred, `reply` ephemerally). Prefix commands use `ctx.reply`. Catch and log every error.
6. Config: `TERMS_URL` and `PRIVACY_URL` in `BaseAppConfigSchema` as optional URLs with the GitHub defaults; add commented lines to both example files under a "Legal" heading. TASK-1921's empty-means-unset fix already applies.

**Relevant code**
- `apps/bot/src/command-router.ts:20` `createCommandRouter`: the middleware list and `onCommandRun`.
- `packages/discord/src/router/router.ts:70` `dispatchInteraction`: context menus are deferred ephemerally before the pipeline; slash commands are not.
- `packages/discord/src/command/context.ts:77` `reply`: follows up when already replied or deferred.
- `packages/services/src/activity/command-usage-recorder.ts`: style reference for a small service with injected clock.

**Pitfalls**
- Never delay the command's own reply: Discord gives 3 s to acknowledge an interaction. The notice comes after.
- Do not show the notice for autocomplete or component interactions.
- Do not store anything for a user who only triggered XP or AutoMod: the notice is about commands.
- The user's `next dev` shares this checkout's database: after the migration, ask the coordinator to tell the user to migrate locally.

**Out of scope**
- The AI consent prompt (TASK-1933). Legal text (TASK-1923).
