## 3. Gotchas & Important Notes
- **Spotify Web API Keys**: `SPOTIFY_CLIENT_ID` and `SPOTIFY_CLIENT_SECRET` can be generated freely from Spotify Developer Dashboard. Even without them, the adapter gracefully falls back to session cookies (`SPOTIFY_DC`/`SPOTIFY_KEY`) and public Deezer metadata.
- **No Native DRM Needed**: Audio bridging matches ISRC, artist, and track title with SoundCloud and YouTube official tracks, delivering identical 160-320kbps Opus audio without proprietary DRM decryption hurdles.
