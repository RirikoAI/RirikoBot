**Pitfalls**
- Prod installs:
  - Pass `--ignore-scripts`: the root `prepare: husky` script fails when devDependencies are missing.
  - Set `HUSKY=0` in the build stage too.
  - pnpm 10 already skips dependency build scripts (`protobufjs` and `@google/genai` are in `ignoredBuilds`), and none are needed at runtime.
- pnpm does not hoist (`shamefully-hoist=false`):
  - `@ririko/*` and their dependencies resolve through per-package `node_modules` symlinks into `/app/node_modules/.pnpm`.
  - Copy those trees to the same paths so the relative symlinks still resolve.
  - Check with a run, not by reading the Dockerfile.
- The manifest COPY list names every workspace package. Adding a package later breaks the build until the list is updated. TASK-1213's CI job catches this.
- fontconfig writes a cache under `$HOME`. The `ririko` user has no home directory, so set `HOME=/tmp` or canvas logs warnings.
- tini must be PID 1:
  - FFmpeg child processes need reaping.
  - `main.ts` handles SIGTERM for graceful shutdown.
- FFmpeg from bookworm is large. Report both image sizes (`docker image ls`) in the PROGRESS entry. There is no hard size limit.
- Docker on this machine is Docker Desktop with a Linux engine. Run `docker` from the Bash tool or PowerShell. In Git Bash, a PATH entry with a space can break a bare `docker` call, so use the full path or PowerShell if that happens.
- Never copy, mention or document `packages/music-private` in the Dockerfile or the docs, beyond excluding it in `.dockerignore`.
