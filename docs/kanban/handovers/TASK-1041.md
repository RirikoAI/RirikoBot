## 1. Summary of Changes
- **Database Repositories**:
  - Implemented `DungeonSeasonRepository`, `DungeonFloorRepository`, and `UserDungeonProgressRepository` in `packages/database/src/repositories/dungeon.repository.ts` with dual SQLite/Postgres support.
  - Exported and tested in `packages/database/src/repositories/dungeon.repository.test.ts`.
- **Scaling Engine**:
  - Implemented `ScalingEngine` in `packages/services/src/waifu-tcg/dungeon/scaling-engine.ts` with 4 mathematical models (`LINEAR`, `POLYNOMIAL`, `EXPONENTIAL` with $r = 0.085$, `HYBRID`).
  - Configurable boss multipliers: Standard (1.0x), Mini-Boss (1.75x on every 5th floor), Major Boss (3.2x on every 10th floor).
  - Stat curve verification against Section 7.5 baseline progression table up to F50.
- **Multi-Layer Elemental Wards**:
  - Implemented `ElementalWard` in `packages/services/src/waifu-tcg/dungeon/elemental-ward.ts`.
  - Non-matching element strikes are absorbed 100% (0 damage to boss).
  - Matching element strikes deplete the barrier layer and shatter it upon reaching 0 HP, moving to the next layer until all are broken.
- **Seasonal Environmental Affixes**:
  - Implemented `SeasonalAffixHandler` in `packages/services/src/waifu-tcg/dungeon/seasonal-affixes.ts`.
  - S1 (*Infernal Crucible*): *Scorched Earth* (6% burn DoT/2 turns unless Earth shielded or Water purified), *Heat Haze* (-15% CRIT non-Fire).
  - S2 (*Abyssal Maelstrom*): *Torrential Deluge* (-25% SPD, Lightning bounces +20%), *Tidal Barrier* (Boss heals 8% max HP if not afflicted with Freeze/Shock within 3 turns).
  - S3 (*Celestial Twilight*): *Radiant Flare & Void Drain* (2.0x mutual catastrophe, healing suppressed by 40%).
- **Dungeon Runner**:
  - Implemented `DungeonRunner` in `packages/services/src/waifu-tcg/dungeon/dungeon-runner.ts` coordinating combat simulator, energy deduction, prerequisite floor locking, soft enrage (Turn 10+ +100% ATK/turn + true damage), and user dungeon progress recording.
