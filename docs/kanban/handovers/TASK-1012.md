## 2. Technical Scope & Implementation Completed

### 2.1. Waifu Drop Manager (`packages/services/src/waifu-tcg/drops/drop-manager.ts`)
- **Drop Channel Check**: Triggers only in designated drop channels or configured guild channels.
- **Message Threshold**: Spawns drops after 50–100 messages from unique users (configurable per guild via `recordMessageActivity`).
- **Active Hours Window**: 08:00 to 23:00 local time check (`isWithinActiveHours`).
- **Interactive Claim Lifecycle**:
  - Spawns active drop with 60-second claim window.
  - Spawns button component with customId `tcg:claim:<dropId>`.
- **Anti-Sniping Cooldown**: 5-minute cooldown (`claimCooldownMs = 5 * 60 * 1000`) for the claimant of the previous drop.
- **Concurrency & Atomic Claim Lock**: First claimant atomically claims the card; subsequent claims receive a friendly error message citing who already claimed the card.

### 2.2. Card Dismantling Engine (`packages/services/src/waifu-tcg/card/dismantle-service.ts`)
- Prevents dismantling if:
  - Card is marked `isFavorite = true` ("Card is favorited and protected from accidental dismantling. Unfavorite it first to dismantle.").
  - Card is not `IDLE` (e.g. `EQUIPPED`, `IN_TRADE`, `IN_MARKET`).
- Exact Crafting dust yield table:
  - `COMMON`: 10 Dust
  - `UNCOMMON`: 25 Dust
  - `RARE`: 75 Dust
  - `SUPER_RARE`: 200 Dust
  - `ULTRA_RARE`: 500 Dust
  - `SECRET_RARE`: 1,200 Dust
  - `SIR`: 3,000 Dust
  - `MYTHIC`: 10,000 Dust

### 2.3. Dual-Dispatch Discord Command Suite (`apps/bot/src/commands/tcg/card.command.ts`)
- Dual-dispatch parity (Slash and Prefix `!card`):
  - `/card collection [filter] [sort]` (paginated cards embed, filter by element or rarity, sort by level, rarity, name)
  - `/card inspect <card_id>` (detailed stat card, foil effect, active skills, passives, Section 24 source attribution)
  - `/card claim [drop_id]` (claims active drop in guild/channel)
  - `/card equip <card_id>` (sets state to EQUIPPED, swaps existing combat vanguard to IDLE)
  - `/card favorite <card_id>` (toggles isFavorite lock)
  - `/card dismantle <card_id>` (dismantles card for crafting dust)
