## GROOMING · 2026-10-10T20:59:20Z · claude-opus-5-5 (coordinator)

**Approach**
- Docusaurus 3, classic preset, TypeScript.
- Docs config: `docs: { path: '../docs', routeBasePath: 'docs', exclude: ['kanban/**', 'archive/**', 'hosting.md', 'dockerhub/**'] }`.
- Local search: `@easyops-cn/docusaurus-search-local`, or an equivalent that needs no external service.

**Pitfalls**
- The root scripts `docs:dev` and `docs:build` use `pnpm --filter website`.
- Add `website/build` and `website/.docusaurus` to `.gitignore` and `.prettierignore`. ESLint may need an ignore for `website/build`.
- MDX v3 is strict about `<` and `{` in plain Markdown. Set `markdown.format: 'detect'`, so `.md` files parse as CommonMark and the existing docs need no MDX escaping.

## GROOMING · 2026-10-10T21:18:21Z · claude-opus-5-5 (coordinator) · maintainer decisions

**Maintainer decisions (2026-10-11)**
- **URL** (coordinator's call): `ririko.ai` is the landing page and `ririko.ai/docs` the docs. One domain, one build, one deploy, and the docs pages share the landing page's look. A separate wiki subdomain would need a second DNS record and certificate and would split search.
- **A wiki you can reach locally**: `pnpm docs:dev` runs the full site on your machine with hot reload. `pnpm docs:build && pnpm docs:serve` runs the built site offline. Both are acceptance items.
- **Readers**: keep the navigation flat and predictable. Each sidebar entry is a task the reader wants to do ("Install with Docker", "Turn on music"), not an internal module name.
