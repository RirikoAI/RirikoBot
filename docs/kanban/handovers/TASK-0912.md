## 2. Key Objectives & Scope
1. **Dual-Dispatch Auto-Voice Configuration & Control Commands (`apps/bot/src/commands/autovoice/`)**:
   - `/autovoice setup`: Setup or update a "Join to Create" parent channel (`channel`, optional `template`, `limit`, `bitrate`). Enforces `ManageChannels` or `ManageGuild` permission.
   - `/autovoice remove`: Unconfigure a "Join to Create" generator channel (`channel`).
   - `/autovoice list`: List all configured auto-voice generators in the server.
   - Channel Owner In-Channel Controls (`/voice`):
     - `/voice name`: Rename current dynamic voice channel (`name`).
     - `/voice limit`: Set user limit (`limit` from 0 to 99).
     - `/voice lock`: Lock or unlock voice channel (`locked: true/false`).
     - `/voice permit`: Grant a specific user connect permission (`user`).
     - `/voice kick`: Disconnect / kick a user from the channel (`user`).
     - `/voice claim`: Claim ownership if the previous owner has left the voice channel.
     - `/voice transfer`: Transfer channel ownership to another active participant in the channel (`user`).
   - Legacy prefix parity:
     - `!autovoice setup` / `!avc setup`
     - `!autovoice remove` / `!avc remove`
     - `!autovoice list` / `!avc list`
     - `!voice name` / `!vname`
     - `!voice limit` / `!vlimit`
     - `!voice lock` / `!vlock`
     - `!voice unlock` / `!vunlock`
     - `!voice permit` / `!vpermit`
     - `!voice kick` / `!vkick`
     - `!voice claim` / `!vclaim`
     - `!voice transfer` / `!vtransfer`
