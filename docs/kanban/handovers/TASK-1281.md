## GROOMING · 2026-10-02T05:25:08Z · Claude Code (Opus 5.5)

**Approach**
1. Extend `TransformedData` (`types.ts:166`) with five arrays, typed as sqlite insert shapes like the existing ones: `guildWelcomers`, `guildFarewells`, `freeGameChannels`, `aiGuildPreferences` and `imageGuildSettings`.
2. In the transformer, collect the `guild_config` values per guild first, then build the rows:
   - **Welcome card.** Build a `guild_welcomer` row when `welcomer_channel` is set:
     - `isEnabled` comes from `isEnabledValue(welcomer_enabled)`, and is false when that row is missing.
     - `backgroundUrl` comes from `welcomer_bg`.
     - `backgroundFile` stays null.
     - The template and theme keep the schema defaults.
   - **Farewell card.** Build a `guild_farewell` row the same way.
   - **Free-games channel.** Build a `free_game_channels` row from `freeGamesChannelId`.
   - **Free-game announcements.**
     - Each one gets that channel as its `channelId`.
     - Skip announcements for a guild with no free-games channel.
     - Convert each id to the 2.0 form, using the 2.0 id builders in `epic.provider.ts:88` and `steam.provider.ts:59`: an Epic id or slug becomes `epic-<id>`, and a Steam URL `/app/<id>/` becomes `steam-<id>`.
   - **AI model.** Normalise `ai_model` with the `packages/core/src/config/ai.ts` helpers.
     - If it is valid, set `providerOverride` / `modelOverride` on `ai_guild_preferences`.
     - If it is not, add a warning and skip it.
   - **Image model.** `stablediffusion_model` becomes an `image_guild_settings` row with `defaultProvider: 'replicate'`.
   - **Old columns.** Stop setting `welcomer*` / `farewell*` on `guildSettings`.
3. In the engine:
   - Insert the new arrays after `guilds` and `guildSettings`.
   - Add them to `migratedCounts`.
   - Check whether `verify` compares per-table counts, and extend it if it does.
4. Raise a warning for the `configuration` credentials that are not migrated.
   - Name the credentials that are present. Never log their values.
   - Put it in the summary that `runLegacyUpgrade` logs.
5. Fixture and tests:
   - Add fixture rows for `farewell_bg`, `ai_model` and `stablediffusion_model`.
   - For `ai_model`, use one valid choice. A second guild with an invalid model is optional.
   - Assert every row in `migration.test.ts`.
6. In `docs/migrations.md` section 2, document the new mappings and the `twitch_channel` decision.

- Free-game announcements of a guild without a free-games channel are skipped, because they would have no channel to point at.
- `apps/bot` imports `@ririko/database` from `dist`. Run `pnpm --filter @ririko/database build` before bot tests that use the new fields.
