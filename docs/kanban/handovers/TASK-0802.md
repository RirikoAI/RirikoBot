## 2. Key Deliverables & Implemented Architecture

### 2.1. `StreamNotificationDispatcher`
Implemented in `packages/services/src/stream-platforms/dispatcher.ts`:
- **Exactly-Once Idempotency Enforcement**:
  - Checks `stream_announcements` with composite idempotency key:
    `const idempotencyKey = `${stream.platform}:${stream.streamId}:${sub.guildId}:${sub.channelId}`;`
  - Guarantees that even if polling triggers multiple times or the bot restarts during a stream session, the live notification is dispatched **exactly once per stream per channel**.
  - Upon successful message dispatch, saves idempotency record with `guildId`, `channelId`, and Discord `messageId`.
- **Thumbnail Proxy & Discord Attachment CDN**:
  - Fetches thumbnail binary buffer from external stream preview URLs (Twitch Helix, YouTube, TikTok).
  - Computes SHA-256 integrity hash using `node:crypto`.
  - Creates Discord `AttachmentBuilder` (`attachment://stream_thumb.jpg`) and sets embed image to direct attachment URL.
  - Caches record in `stream_assets` table (`stream_id`, `original_url`, `discord_attachment_url`, `file_hash`).
  - Resilient fallback: If external image fetch fails or times out, safely falls back to direct URL embedding so live notifications are never blocked or dropped.
- **Custom Template Interpolation**:
  - Supports placeholder replacement:
    - `{streamer}` $\to$ creator's display name or login.
    - `{title}` $\to$ stream title.
    - `{game}` $\to$ stream category or game name.
    - `{platform}` $\to$ platform name (Twitch, YouTube, TikTok).
    - `{url}` $\to$ canonical stream URL.
    - `{role}` $\to$ Discord role mention `<@&roleId>` if configured on the subscription.
  - Color-coded platform embeds (Twitch purple `0x9146ff`, YouTube red `0xff0000`, TikTok cyan `0x00f2fe`).
