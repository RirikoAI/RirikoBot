## 2. Key Deliverables & Implemented Architecture

### 2.1. Dual-Dialect `GiveawayRepository` (`@ririko/database`)
Implemented in `packages/database/src/repositories/giveaway.repository.ts`:
- **Giveaway Lifecycle CRUD**:
  - `findById(id)`: Resolves giveaway by ID.
  - `findByMessageId(messageId)`: Resolves giveaway by Discord message ID.
  - `create(data)`: Generates UUID PK if missing, normalizes timestamps (`startsAt`, `endsAt`), sets `isEnded = false`.
  - `update(id, data)`: Updates giveaway fields.
  - `delete(id)`: Cascade deletion in atomic transaction (cleans up entries, winners, and giveaway record).
  - `count()`: Dialect-agnostic count query.
  - `listActiveGiveaways(guildId?)`: Filters unended giveaways (`isEnded = false`).
  - `listExpiredPendingGiveaways(now)`: Queries overdue unended giveaways (`isEnded = false AND endsAt <= now`) for reboot crash reconciliation.
  - `listGuildGiveaways(guildId, limit)`: Paginated historical query ordered by creation date descending.
- **Entry & Multiplier Tracking**:
  - `addEntry(giveawayId, userId, bonusMultiplier)`: Atomic insert with conflict suppression (`onConflictDoNothing()`).
  - `removeEntry(giveawayId, userId)`: Deletes user entry.
  - `getEntries(giveawayId)`: Retrieves all participants and their bonus multipliers.
  - `getEntryCount(giveawayId)`: Fast aggregate entry count query.
  - `hasUserEntered(giveawayId, userId)`: Fast boolean existence check.
- **Winner Persistence & Atomic End Transitions**:
  - `recordWinners(giveawayId, userIds, isReroll)`: Inserts winner records into `giveaway_winners`.
  - `getWinners(giveawayId)`: Retrieves recorded winners.
  - `endGiveaway(giveawayId, winnerUserIds)`: ACID transaction setting `isEnded: true` and recording initial winners.
- Validated via 6 unit tests in `packages/database/src/repositories/giveaway.repository.test.ts`.

### 2.2. Giveaways Engine Core (`GiveawayEngine`, `@ririko/services`)
Implemented in `packages/services/src/giveaways/engine.ts`:
- **Crash-Resilient Lifecycle & Scheduler**:
  - `start()`: Immediately invokes `tick()` upon bot startup to reconcile overdue giveaways left pending during downtime, then starts periodic sweep timer (`checkIntervalMs = 15s`).
  - `stop()`: Clean timer disposal on shutdown.
  - `tick()`: Sweeps expired pending giveaways and calls `rollAndEndGiveaway`.
- **Deterministic Weighted Winner Selection**:
  - `selectWinners(entries, winnerCount, existingWinners, rngFn)`:
    - Excludes prior winners.
    - Handles zero entrants or entrants $\le$ `winnerCount`.
    - Weighted random sampling without replacement using cumulative multiplier thresholds.
    - Uses injectable pseudo-random function (`rngFn`) for 100% deterministic testing as required by `docs/testing.md`.
- **Configurable Entry Qualification Gates**:
  - `validateEntry(member, requirements)`:
    - Discord account age barrier (`minAccountAgeDays`).
    - Server tenure barrier (`minServerTenureDays`).
    - Blacklisted roles restriction (`blacklistedRoleIds`).
    - Required roles check (`requiredRoleIds`).
    - Automatic booster 2x multiplier and custom role bonus calculations (`bonusRoles`).
- **Reroll Engine**:
  - `reroll(giveawayId, customWinnerCount)`: Selects new winners strictly excluding previous winners and marks records with `isReroll = true`.
- **UI Embed & Button Components Factory**:
  - `formatGiveawayEmbed(giveaway, entryCount, winners)`: Modern rich aesthetics with relative timestamps (`<t:timestamp:R>`), entry tallies, and requirement listings.
  - `formatGiveawayButton(giveawayId, isEnded, entryCount)`: Action row button `🎉 Enter ({count})` (disabled when ended).
- Exported via `packages/services/src/giveaways/index.ts` and `packages/services/src/index.ts`.
- Validated via 12 unit tests in `packages/services/src/giveaways/__tests__/giveaway.test.ts`.
