## 1. Summary of Work Accomplished

`TASK-1322` implements the Discord user-facing command layer, interactive component matrix, native attachment delivery, and guild configuration parity for the AI Image Generation subsystem in accordance with Section 14 & 15 of [`BLUEPRINT.md`](file:///Z:/Projects/ririko-v2-2026/BLUEPRINT.md) and [`docs/adr/ADR-006`](file:///Z:/Projects/ririko-v2-2026/docs/adr/ADR-006-image-generation-and-canvas-synthesis.md).

### Files Created & Modified

1. **Commands Layer**:
   - [`apps/bot/src/commands/images/imagine.command.ts`](file:///Z:/Projects/ririko-v2-2026/apps/bot/src/commands/images/imagine.command.ts):
     - **Dual-Dispatch `/imagine` & `!imagine`**: Full parity supporting Slash and Prefix invocations with aliases (`img`, `ai-image`, `generate-image`).
     - **Configurable Options**:
       - `prompt` (required string)
       - `negative_prompt` (optional string)
       - `aspect_ratio` (`1:1`, `16:9`, `9:16`, `4:3`, `3:4`)
       - `preset` (`anime`, `photoreal`, `pixel-art`, `fantasy`, `cyberpunk`, `none`)
       - `provider` (`auto`, `gemini`, `comfyui`, `replicate`, `mock`)
     - **Flexible Prefix Flag Parsing**: Supports `--ar <ratio>`, `--preset <style>`, `--provider <backend>`, and `--negative <neg prompt>` in arbitrary order.
     - **Discord Attachment Delivery**: Attaches synthesized image buffers directly using `AttachmentBuilder` (`attachment://imagine.png`), preventing expired external URLs or broken CDNs.
     - **Rich Metadata Embed**: Displays prompt, negative prompt, provider name, preset, aspect ratio, duration in seconds, and requester footer.
     - **Interactive Action Row Matrix**:
       - 🔁 **Regenerate** (`imagine:regen:<jobId>`): Fetches previous job parameters and generates a fresh iteration for the requester.
       - ❌ **Dismiss** (`imagine:dismiss:<userId>`): Safely deletes the image message for the requester.
     - **Invoker Component Filtering**: Backed by `attachOwnerCollector` with ephemeral hints for unauthorized users, plus global interaction fallback in `main.ts`.
   - [`apps/bot/src/commands/images/config.command.ts`](file:///Z:/Projects/ririko-v2-2026/apps/bot/src/commands/images/config.command.ts):
     - **Dual-Dispatch `/stablediffusion-model`**: Server administration command (`ManageGuild` permission) to inspect or configure the default image preset and provider.
     - **Dual-Dispatch `/setup-stablediffusion-api`**: Legacy 1.4.0 command deprecation notice in accordance with ADR-011 (Secrets Management & Credential Security), explaining that plaintext database token storage is discontinued and guiding admins to use environment variables (`GEMINI_API_KEY`, `COMFYUI_BASE_URL`, `REPLICATE_API_TOKEN`).
   - [`apps/bot/src/commands/images/index.ts`](file:///Z:/Projects/ririko-v2-2026/apps/bot/src/commands/images/index.ts): Barrel exporter for all image commands and button handlers.

2. **Bot Services & Main Entrypoint**:
