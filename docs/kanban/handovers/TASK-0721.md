## 2. Key Deliverables & Implemented Architecture

### 2.1. Pattern Matcher Engine & Specialized Rules
Located in `packages/services/src/moderation/rules/`:
- **`InviteFilterRule`**:
  - Detects Discord invite links across `discord.gg/*`, `discord.com/invite/*`, `discordapp.com/invite/*`, `discord.me/*`, `discord.io/*`, and `discord.li/*`.
  - Supports invite code whitelists (e.g. guild's own vanity URL, official partner links) with case-insensitive normalization.
- **`PhishingShieldRule`**:
  - **Zero-Width Stripping**: Removes zero-width and invisible characters (`\u200B`, `\u200C`, `\u200D`, `\uFEFF`, `\u00AD`, `\u2060`, `\u180E`) inserted to bypass text filters.
  - **Homoglyph Normalization**: Normalizes lookalike Cyrillic, Greek, and Unicode characters (`а, с, е, о, р, ѕ, х, у, і, ј, ԁ, α, ο, ν, ρ`) to ASCII equivalents.
  - **Leetspeak & Obfuscation Decoding**: Decodes visual substitutes (`0->o`, `!/|->i`, `1->i`, `3->e`, `4/@->a`, `5/$->s`, `7->t`, `8->b`, `vv->w`, `rn->m`, `cl->d`, `dlscord->discord`).
  - **Domain Verification**: Whitelists legitimate official domains (`discord.com`, `discord.gg`, `discordstatus.com`, `steamcommunity.com`, etc.) to prevent false positives while detecting spoofed domains and typosquats (`discord-nitro.gift`, `discord-airdrop.gift`, `steamcommunilty.com`).
  - **Scam Phrase Detection**: Identifies scam phrases (`free nitro`, `nitro airdrop`, `steam 50$`) combined with external links.
- **`MentionSpamRule`**:
  - Scans for user mentions `<@!?\d+>`, role mentions `<@&\d+>`, and `@everyone` / `@here`.
  - Seamlessly integrates pre-parsed `context.mentions` when provided.
  - Compares total mention count against configurable threshold (default: 5).
- **`BurstSpamRule`**:
  - **Velocity Sliding Window**: Tracks message velocity per `(guildId, userId)` (default: 5 messages in 3 seconds).
  - **Duplicate Message Detector**: Detects rapid copy-paste spam ($\ge 3$ identical messages within 10 seconds).
  - **Memory Leak Protection**: Automatic TTL cleanup purges entries older than 60 seconds. Supports per-user/guild `reset()`.

### 2.2. AutoMod Coordinator Service (`AutoModService`)
Located in `packages/services/src/moderation/automod.service.ts`:
- **Priority Pipeline**: Evaluates rules in security priority order:
  1. `PHISHING_SHIELD` (Critical malicious threat)
  2. `INVITE_FILTER` (Unauthorized advertising)
  3. `MENTION_SPAM` (Mass ping disruption)
  4. `BURST_SPAM` (Chat flooding)
- **Configurable Caching & DB Sync**: Loads guild rules from `ModerationRepository` with a 5-minute TTL cache and instant invalidation support (`setRuleConfig`, `invalidateRuleCache`).
- **Comprehensive Exemption Evaluation**:
  - Automated bots ignored.
  - Guild Owner bypassed.
  - Members with `Administrator`, `ManageGuild`, `ManageMessages`, `ModerateMembers`, or `BanMembers` bypassed.
  - Exempt channels bypassed.
  - Exempt roles bypassed.
- **Action Execution & EventBus Dispatch**:
  - Calls `rawMessage.delete()` on message deletion actions.
  - Bridges with `WarningEscalationService` and `ModerationActionService` for punitive automod warnings and timeouts.
  - Emits `moderation:automodViolation` event on `EventBus`.
