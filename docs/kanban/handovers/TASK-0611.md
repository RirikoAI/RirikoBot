## 3. Roadblocks, Gotchas & Decisions Made
- **Sub-Millisecond Monotonic Timestamps**: When recording user and assistant turns rapidly in high-throughput loops or tests, `Date.now()` produces identical millisecond timestamps. Added monotonic timestamp generation in `ConversationManager` ensuring user message is always strictly before assistant message.
- **Optional `id` in Drizzle Inserts**: Parametrized `AiRepository` with `InsertAiConversation` and `InsertAiMessage` (`Omit<..., 'id'> & { id?: string }`) so callers can omit `id` and allow the repository to auto-generate UUID keys.
