## 3. Decisions & Gotchas
- When transitioning between the List View and Inspect View in `cards.command.ts`, we pass `files: []` when returning to the List View to clear the card image attachment, and attach `card.png` when entering the Inspect View.
- In `cards:equip:<id>`, we set all existing equipped cards for the user to `IDLE` before updating the target card to `EQUIPPED`, preserving the invariant that only one card is the active vanguard.
- Cards locked in `IN_TRADE` or `IN_MARKET` disable the equip button to prevent race conditions with marketplace listings or active P2P trade sessions.
