## 1. Summary of Completed Work
Implemented the zero-polling reactive embed controller and interactive 2-row button matrix for Discord music channels, completing Section 5 of `docs/music.md`:

1. **Music Embed Controller (`apps/bot/src/controllers/music-embed.controller.ts`)**:
   - **Zero Polling Architecture**: Completely eliminates legacy 1.4.0's problematic `setInterval(..., 10000)` polling loops that routinely hit Discord HTTP 429 rate limits.
   - **Event-Driven Subscriptions**:
     - Hooks directly into `MusicPlayerService` events (`trackStart`, `queueEnd`, `stateChange`, `volumeChange`, `loopChange`, `filterChange`, `queueCleared`, `queueShuffled`).
     - Re-renders and edits the persistent controller message in-place only when actual playback state transitions occur.
     - Dynamically updates channel topic: `🎵 Now Playing: <Title> (<Duration>)` during playback and resets topic when idle.
2. **Interactive 2-Row Button Matrix (`buildControllerButtonRows`)**:
   - **Row 1 (Playback Controls)**:
     - `music_previous` (`⏮️`, Primary): Back to previous track in history stack (disabled if no history).
     - `music_play_pause` (`▶️` / `⏸️`, Success/Primary): Toggles pause and resume (disabled when idle).
     - `music_skip` (`⏭️`, Primary): Skips active track (disabled if no upcoming tracks).
     - `music_stop` (`🛑`, Danger): Stops playback, clears queue, and leaves voice.
     - `music_mute_unmute` (`🔇` / `🔊`, Secondary): Toggles volume to 0% and restores previous gain.
   - **Row 2 (Queue & Utility Controls)**:
     - `music_loop` (`🔁`, Secondary/Primary): Cycles loop mode (`Off`, `Track`, `Queue`) with dynamic label.
     - `music_shuffle` (`🔀`, Secondary): Randomizes upcoming tracks (disabled if queue < 2).
     - `music_lyrics` (`📝`, Secondary): Ephemeral lyrics search for currently playing track.
     - `music_queue` (`📜`, Secondary): Ephemeral queue display with track pagination.
     - `music_refresh` (`🔄`, Secondary): Forces controller re-sync.
3. **Dedicated Music Channel (`#music`) Auto-Play**:
   - Integrated into `messageCreate` gateway listener.
   - Automatically detects song queries typed as plain chat messages in the configured music channel.
   - Deletes user messages to maintain a clean controller channel interface.
   - Plays query if user is in voice channel, or displays a self-deleting (5s) ephemeral-style warning if not connected.
4. **Command Parity & Setup (`setup-music`)**:
   - Added `/setup-music [channel]` command allowing administrators to designate or initialize the dedicated music channel controller.
   - Persists `channelId` and `lastMessageId` in `music_channels` table via `MusicRepository`.

## 3. Key Design Decisions & Gotchas
- **Zero Polling Invariant**: All controller updates are triggered strictly by domain events from `MusicPlayerService` and direct user button interactions. No timers or polling intervals exist.
- **Persistent Message Recovery**: If a user or moderator deletes the controller message in the dedicated channel, `updateController` gracefully catches the missing message and sends a new controller embed, updating `lastMessageId` in `music_channels`.
