## 2. Implemented Features & Changes
1. **New Workspace Package (`packages/music`)**:
   - Initialized `@ririko/music` (`v2.0.0`) in `pnpm-workspace.yaml` and registered composite project reference in root `tsconfig.json`.
   - Isolates voice and audio processing dependencies from core domain services.
2. **Audio Types & Contracts (`packages/music/src/types.ts`)**:
   - Defined `MusicSourceAdapter`, `ResolvedTrack`, `ResolvedPlaylist`, `MusicSearchResult`, `AdapterHealth`, and `ExtractorPipelineOptions`.
   - Guaranteed stream retrieval via `getStream: () => Promise<Readable | NodeJS.ReadableStream>`.
3. **Pluggable Source Adapters (`packages/music/src/extractors/`)**:
   - **`YouTubeAdapter`** (priority 10): Resolves standard watch URLs, `youtu.be` shortlinks, shorts, `music.youtube.com`, and multi-track playlists with search capability and mobile client emulation options.
   - **`SpotifyAdapter`** (priority 20): Parses tracks, albums, and playlists from both HTTPS URLs and `spotify:` URIs into rich metadata.
   - **`SoundCloudAdapter`** (priority 30): Extracts standalone tracks and playlist sets directly from SoundCloud URLs.
   - **`DeezerAdapter`** (priority 40): Parses Deezer tracks, albums, playlists, and shortlinks with preview stream extraction.
   - **`DirectAdapter`** (priority 50): Direct playback for raw audio streams (`.mp3`, `.ogg`, `.opus`, `.wav`, `.flac`, `.aac`, `.m4a`, `.m3u8` live streams).
4. **Extractor Orchestration Pipeline (`packages/music/src/extractors/pipeline.ts`)**:
   - Manages registered adapters sorted by priority.
   - Implements URL detection and automatic delegating to matching source adapter.
   - Implements keyword search with primary and secondary fallback providers (e.g. YouTube -> SoundCloud).
   - Bridges Spotify metadata-only tracks to playable audio streams by automatically querying stream providers on `getStream()`.
   - Collects latency and health status via `healthCheck()`.
5. **Unit Test Suite (`packages/music/src/extractors/extractors.test.ts`)**:
   - 19 test cases verifying pattern matching, single track & playlist resolution, metadata bridging, keyword search, health checks, and error handling.
