**Pitfalls**
- With `setup_remote_docker`, containers run on a remote engine:
  - Host bind mounts and host ports do not reach them.
  - The smoke script must check through `docker run` and `docker exec` only, which is what the earlier tasks set out to do.
  - If a check relies on the host, fix the script here and note it in the PROGRESS entry.
- Docker layer caching (`docker_layer_caching: true`) may not be available on this CircleCI plan. Leave it off unless the PR run shows it works.
- The worker cannot see CircleCI results, because workers never push. Run `verify_cmd` locally. The coordinator checks the first CI run on the STORY-121 PR before setting DONE.

**Out of scope**
- Pushing images to a registry, or any release or tag workflow.
- Path filtering or dynamic config to skip the job. It runs on every push, like the other jobs.
