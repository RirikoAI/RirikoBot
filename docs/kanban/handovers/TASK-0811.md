### 2.2. Multi-Provider Free Games Fetchers (`FreeGameProvider`)
Implemented in `packages/services/src/free-games/providers/`:
- **`EpicGamesProvider`** (`epic.provider.ts`):
  - Fetches from Epic Games Store promotions API (`https://store-site-backend-static.ak.epicgames.com/freeGamesPromotions`).
  - Identifies 100% discount promotions (`discountPercentage === 0`).
  - Distinguishes active promotional offers from upcoming offers (`isUpcoming` flag and "(Coming Soon)" title suffix).
  - Resolves product slugs and high-resolution banner images (`OfferImageWide`, `DieselStoreFrontWide`, `Thumbnail`).
  - Formats store URLs: `https://store.epicgames.com/p/{slug}`.
- **`SteamFreeGamesProvider`** (`steam.provider.ts`):
  - Fetches from Steam featured categories API (`https://store.steampowered.com/api/featuredcategories/?l=english`).
  - Identifies 100% discount giveaway promotions (`discount_percent === 100` or `final_price === 0 && original_price > 0`).
  - Formats store URLs: `https://store.steampowered.com/app/{appId}/`.
  - Normalizes headers, capsule images, and discount expiration timestamps.

### 2.3. Free Games Announcer Engine (`FreeGamesEngine`)
Implemented in `packages/services/src/free-games/engine.ts`:
- Periodic polling loop with configurable interval (default: 30 minutes).
- Dynamic provider registry (`registerProvider`, `getProvider`).
- Automatic catalog synchronization with `FreeGameRepository` on active game discovery.
- Deduplicated guild announcements: iterates configured target guilds, checks `isGameAnnounced`, calls `onAnnounceGame`, and commits `recordAnnouncement`.
- Rich Discord embed formatter (`formatGameEmbed`) with store link buttons, relative timestamps (`<t:timestamp:R>`), original strike-through prices, and provider theme colors.
- Exported from `packages/services/src/free-games/index.ts` and `packages/services/src/index.ts`.
- Validated via 7 unit tests in `packages/services/src/free-games/__tests__/free-games.test.ts`.
