  - Implemented `tokenizeCommandArgs(input)`:

    - Handles single and double-quoted strings (`"YOASOBI Idol"`).
    - Preserves escaped quotes (`\"`).
    - Strips redundant whitespaces and handles empty strings.
- **Dual Option Resolvers ([`packages/discord/src/command/options.ts`](file:///z:/Projects/ririko-v2-2026/packages/discord/src/command/options.ts))**:
  - `SlashOptionsResolver`: Delegates directly to Discord's `ChatInputCommandInteraction.options`.
  - `PrefixOptionsResolver`: Positionally maps tokenized prefix arguments to schema definitions:
    - Trailing string joining for multi-word parameters (e.g. reason/notes).
    - Type conversion & strict validation for `string`, `integer`, `number`, `boolean` (`true`/`false`, `1`/`0`, `yes`/`no`).
    - Mention and snowflake resolution for `User`, `GuildMember`, `Channel`, and `Attachment`.
    - Emits structured `ValidationError` from `@ririko/core` on required parameter absence or type mismatch.

  - `SlashCommandContext`: Wraps `ChatInputCommandInteraction`, handles deferred and follow-up states.
  - `PrefixCommandContext`: Wraps `Message`, manages typing indicators on `deferReply()`, edits via `editReply()`, and normalizes interaction-specific payload fields.
- **Automated Test Coverage ([`packages/discord/src/command/command.test.ts`](file:///z:/Projects/ririko-v2-2026/packages/discord/src/command/command.test.ts))**:
