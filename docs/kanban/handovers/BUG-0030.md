## GROOMING · 2026-10-02T02:25:22Z · Claude Code (Opus 5.5)

**Approach**
1. In `apps/web/playwright.config.ts`, set `workers: process.env.CI ? 2 : undefined`, with a comment explaining why. CircleCI's `medium` resource class has 2 vCPUs. Playwright counts the host's CPUs (it started 8 workers in build 1615).
2. In `apps/web/e2e/settings.spec.ts`, read the stored prefix first and save a different one. A retry then still changes the setting.

**Evidence** (CircleCI e2e build 1615, `ci/circleci: e2e` on PR #674)
- The tree is identical to build 1614 (`1f8403d`, passed): both trees are `0804c22a`.
- The first attempt's failure screenshot shows "Settings saved.".
- The trace has the action POST taking 308 ms, but the toast appears after the 5 s window, behind about 40 `?_rsc` link prefetches.
- The retry's screenshot shows "Nothing changed." (the prefix was already `?`).

**Out of scope**
- Dashboard prefetch behavior.
- The CircleCI resource class.

## PROGRESS · 2026-10-02T02:29:00Z · Claude Code (Opus 5.5) · REVIEW
