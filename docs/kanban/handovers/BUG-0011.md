## 1. Summary of Work Accomplished
**Root cause.** Crafting dust was shown by every source but stored nowhere. Card dismantling, expeditions, world boss raids, dungeon loot and the `crafting_dust` achievement reward all just printed a number. Enhancement then passed a hard-coded `userDust = 5000` ("for active testing"), so it effectively cost only credits. Expedition and world-raid **credits** were also shown but never paid.

**Fix**
- [catalog.ts](file:///Z:/Projects/ririko-v2-2026/packages/services/src/waifu-tcg/equipment/catalog.ts): new `CRAFTING_DUST` item (`type: 'MATERIAL'`, not tradeable, not buyable). It is seeded like every canonical item, so no schema change is needed.
- [item-grant.service.ts](file:///Z:/Projects/ririko-v2-2026/packages/services/src/waifu-tcg/equipment/item-grant.service.ts): materials stack like consumables. Adds `countOwned(userId, key)` and `consume(userId, key, qty)`; `consume` checks the full amount before changing anything and deletes emptied stacks. The legacy alias `crafting_dust` resolves to `CRAFTING_DUST`, so existing achievement rows now pay real dust.
- [enhancement-service.ts](file:///Z:/Projects/ririko-v2-2026/packages/services/src/waifu-tcg/equipment/enhancement-service.ts): `enhance(userId, userItemId, userCredits)` reads and spends the user's real dust. `getDustBalance(userId)` is added. The bot's hard-coded 5000 is gone, and the success embed shows the dust left.
- Dust and credits now reach the inventory and wallet:
  - `DungeonLootService`: loot dust.
  - `CardDismantleService` (new optional `grants`): dismantle dust.
  - `ExpeditionService` / `BossRaidService` (new optional `RewardPayout { economyRepo, grants }`): credits + dust.
- Bot `services.ts`: one shared `itemGrantService` wires dismantle, expeditions, raids and the boot repair. The inventory list shows quantities for materials.

## 3. Roadblocks, Gotchas & Decisions Made
- Players get no retroactive dust for past dismantles or expeditions; that dust was never recorded anywhere.
- Enhancement spends dust, then updates the item level, then the bot debits credits. These steps are not one transaction; that matches the pre-existing credit flow. A failure between the steps can lose that step's dust.
- Raid badges and expedition card shards are still display-only (no item exists for them). Crafting with dust stays deferred (STORY-160).
