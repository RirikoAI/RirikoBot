## GROOMING · 2026-10-10T21:18:21Z · claude-opus-5-5 (coordinator) · maintainer decisions

**Maintainer decisions (2026-10-11)**: the image is tall and split into sections, and editable in layers so placeholders can be swapped for anime backgrounds, real screenshots and in-depth feature art. The ticket moves to TODO with 5 points.

**Format choice**
- The SVG is the master. Inkscape layers are plain SVG groups, so the file is diffable, versioned and opens with its layers in Inkscape.
- GIMP cannot keep SVG layers, so the render script also writes OpenRaster (`.ora`). That is a zip of one PNG per layer plus `stack.xml`, and GIMP opens it natively with its layers.
- `.psd` is not needed: GIMP's native layered formats are `.xcf` and `.ora`, and `.ora` is the one that can be generated reliably.

**Approach**
- Render with the repository's `@napi-rs/canvas` (it loads the SVG, as the rank cards render images) or `resvg-js`. Rasterise each layer separately for the `.ora`.
- Keep the layout simple: a fixed column with a 64 px grid. Each section gets a background slot, a screenshot slot, a heading and 2 or 3 lines of text.
