## 2. Key Objectives & Scope
1. **AutoVoiceRepository (`packages/database/src/repositories/autovoice.repository.ts`)**:
   - Implemented dual-dialect Drizzle (SQLite & PostgreSQL) repository for `auto_voice_configs`.
   - CRUD & querying operations: `findById`, `findByParentChannelId`, `listByGuildId`, `create`, `upsert`, `update`, `delete`, `deleteByParentChannelId`, `exists`, `count`.
   - Comprehensive unit tests: `packages/database/src/repositories/autovoice.repository.test.ts` (7 tests passing).
2. **AutoVoiceService (`packages/services/src/autovoice/`)**:
   - `handleVoiceStateUpdate(oldState, newState)`:
     - Detects member join/switch into configured "Join to Create" channel.
     - Formats dynamic channel name from template (interpolating `{user}`).
     - Inherits category, position, userLimit, and bitrate.
     - Clones parent channel permission overwrites and grants channel owner management permissions (`ViewChannel`, `Connect`, `Speak`, `ManageChannels`, `MoveMembers`, `MuteMembers`, `DeafenMembers`).
     - Moves member into the newly created voice channel.
     - Concurrency protection: `creationLocks` set prevents duplicate channel spawning on rapid gateway voice state updates.
     - Auto-cleanup on empty: detects when all members leave dynamic channel and cleanly deletes it from Discord and internal registry.
   - `cleanupOrphans(guild)`:
     - Scans guild voice channels on bot startup/recovery, identifies empty child channels left behind after a crash/restart, and prunes them while strictly protecting configured parent channels.
   - Management methods: `isOwner`, `transferOwnership`, `lockChannel`, `setChannelName`, `setUserLimit`, `setBitrate`.
   - Comprehensive unit tests: `packages/services/src/autovoice/__tests__/autovoice.test.ts` (9 tests passing).
3. **Bot Services & Gateway Wiring**:
