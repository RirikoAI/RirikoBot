**Decisions & gotchas**
- `gitleaks git` only reads added lines of each commit, so a value that was added and later removed is still found; deletions are not scanned. The pickaxe (`git log -S`) covers both.
- I ran `git fetch --all --tags --prune` in the main checkout once at the start, which removed stale remote-tracking refs for deleted dependabot branches. No local branch or commit changed. All other work happened in a mirror clone in the scratchpad directory.
- GitHub keeps the objects behind closed PRs and serves them by SHA, so a history rewrite plus force-push never removes the findings that only pull request refs reach. Only a GitHub Support request does.
