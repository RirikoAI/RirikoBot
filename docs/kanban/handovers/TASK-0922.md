### What was built:
1. **Quick Games Engine (`@ririko/services/games/quick-games`)**:
   - `coin-flip.ts`:
     - `flipCoin(options?)`: supports customizable RNG and optional user prediction (`heads` | `tails`).
     - Returns result, won status, and payout calculation.
   - `dice.ts`:
     - `rollDice(count, sides, options?)`: supports NdM dice rolling with per-die and sum results.
     - `rollVsBot(count, sides, options?)`: competitive roll-off against Ririko with win/tie/loss determination.
   - `high-low.ts`:
     - `generateHighLowInitial(options?)`: generates initial number (1-100).
     - `evaluateHighLow(initial, guess, options?)`: generates next number and checks prediction (`higher` | `lower`).
     - Standard tie-break rule: identical number counts as a push/tie.
2. **Dual-Dispatch Mini-Games Commands Suite (`apps/bot/src/commands/games`)**:
   - `tictactoe.command.ts`:
     - `/tictactoe opponent:@user|AI wager:number`: 3x3 interactive ActionRow buttons (`ttt:move:${sessionId}:${cellIndex}`).
     - Human-vs-AI Minimax mode or PvP challenge mode with wager escrowing via `GameEscrowService`.
     - Legacy prefix parity: `!ttt`, `!tictactoe`.
   - `rps.command.ts`:
     - `/rps opponent:@user|AI wager:number`: secret button choices (🪨 Rock, 📄 Paper, ✂️ Scissors).
     - Ephemeral secret selection reveals and evaluates outcome when both players have submitted.
     - Escrowed wager settlement (2x winner pot, full refund on ties).
     - Legacy prefix parity: `!rps`.
   - `highlow.command.ts`:
     - `/highlow wager:number`: interactive Higher (⬆️) or Lower (⬇️) buttons with wager settlement.
     - Legacy prefix parity: `!highlow`, `!high-low`, `!hl`.
   - `coinflip.command.ts`:
     - `/coinflip choice:heads|tails wager:number`: instant flip with escrowed payout.
     - Legacy prefix parity: `!coinflip`, `!coin-flip`, `!cf`.
   - `dice.command.ts`:
     - `/dice count:number wager:number`: solo dice roll or competitive roll vs Ririko with escrow.
     - Legacy prefix parity: `!dice`, `!roll`.
   - `index.ts`:
     - `createGamesCommands(services)`: factory exposing all 5 mini-game commands.
3. **Bot Lifecycle & Main Wiring**:

## 3. Gotchas & Key Decisions
- **Injectable Deterministic RNG**:
  - All quick-game engines (`flipCoin`, `rollDice`, `rollVsBot`, `evaluateHighLow`) accept an optional `rngFn` parameter `() => number` to ensure 100% deterministic test execution without test flakes.
- **Dual Dispatch & Escrow Integration**:
  - Optional wagers are validated against the user's available balance in `EconomyRepository`.
  - When playing against AI, only the player's wager is deducted. If the player wins, they receive their wager back plus winnings.
