## 2. Key Deliverables & Implemented Architecture

  - `findById(id)`
  - `findByPlatformUser(platform, platformUserId)` (case-insensitive platform matching)

  - `updateLiveStatus(id, isLive, lastCheckedAt)`

### 2.2. Multi-Platform Stream Adapters (`StreamPlatformAdapter`)
Implemented in `packages/services/src/stream-platforms/adapters/`:
- **`TwitchStreamAdapter`** (`twitch.adapter.ts`):
  - Client Credentials OAuth token management via `https://id.twitch.tv/oauth2/token` with automatic proactive token refresh.
  - Stream status checking via Twitch Helix API `https://api.twitch.tv/helix/streams`.
  - Batching support up to 100 streamers per Helix request (`getBatchStreamStatus`).
  - Thumbnail URL dimension formatting (`{width}x{height}` $\to$ `1280x720`).
  - User resolution via `https://api.twitch.tv/helix/users`.
  - Graceful degradation when `TWITCH_CLIENT_ID` or `TWITCH_CLIENT_SECRET` is unset without unhandled errors.
- **`YouTubeStreamAdapter`** (`youtube.adapter.ts`):
  - Channel identifier resolution supporting channel IDs (`UC...`), handles (`@...`), and full URLs.
  - Live broadcast detection from public channel endpoints and canonical video links.
  - Zero mandatory external API keys required.
- **`TikTokStreamAdapter`** (`tiktok.adapter.ts`):
  - Resolves username from profile page.
  - Inspects public room status (`$ROOM_DATA` / `LIVE_ROOM` status) for live state and thumbnail extraction.

### 2.3. Stream Watcher Engine (`StreamWatcherEngine`)
Implemented in `packages/services/src/stream-platforms/engine.ts`:
- Periodic polling orchestration with configurable interval (default 60s).
- Query filtering using `listActiveMonitoredStreamers` to avoid wasteful API calls for unmonitored creators.
- Streamer grouping by platform with batch delegation for Twitch.
- Accurate state transition machine:
  - `OFFLINE -> LIVE`: Updates `isLive = true`, records stream event in `stream_events`, triggers `onStreamLive` callback.
  - `LIVE -> OFFLINE`: Updates `isLive = false`, records ended timestamp in `stream_events`, triggers `onStreamOffline` callback.
- Robust error boundary around each polling cycle ensuring individual network timeouts never crash the engine loop.
