SVG (`assets/readme/feature-banner.svg`, 46 `font-family="Karla"` uses): the "Ririko AI" wordmark, the hero tagline, the section titles and the pill labels use Sour Gummy; the small section labels ("MUSIC" and the others), body lines and the version line use Libre Franklin. Pills stay pills, widened only if needed.

5. Run `pnpm readme:banner` twice and compare hashes; look at the PNG and the social card (Read the image) and fix any overflow.
6. Update `assets/readme/README.md`: the files table, the font sentence in "Export again" and the font row of the rights table (Sour Gummy: The Sour Gummy Project Authors; Libre Franklin: The Libre Franklin Project Authors; both SIL OFL 1.1, from github.com/google/fonts).
