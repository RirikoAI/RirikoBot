Implemented the 4-layer heuristic defense specified in Section 34 of `BLUEPRINT.md`:
1. **Quality & Minimum Length**: Rejects messages with fewer than 5 non-whitespace characters (`MIN_LENGTH`).
2. **Rolling Window Cooldown**: Enforces a 60-second reward cooldown per user per guild (`COOLDOWN`).
3. **Levenshtein Distance & Similarity Filter**: Compares normalized message content against the user's recent 3 messages using an $O(\min(m, n))$ space dynamic programming algorithm. Messages with $\ge 80\%$ similarity are rejected (`SIMILARITY_EXCEEDED`).
4. **Automated Burst & Self-Bot Detection**: Evaluates typing interval variance across bursts. If variance drops below $100\text{ms}$, triggers a 30-minute shadow cooldown (`AUTOMATED_BURST`, `SHADOW_COOLDOWN`).
5. **Memory Sweeper**: Automated eviction of stale user tracking states to ensure zero memory leaks.
