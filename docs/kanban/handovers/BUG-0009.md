# BUG-0009 Handover: Fix Tutorial Floor T4 Defeat Counter Card Grant & Stale Metadata Recovery

## 1. Summary of Changes
- **Tutorial Service Active Card Ownership Check (`packages/services/src/waifu-tcg/dungeon/tutorial-service.ts`)**:
  - In `handleTutorialFloor4Defeat(userId, bossElement)`:
    - Previously, if `metadata?.counterCardGiven` was `true`, it unconditionally skipped granting a card, even if `userCard` was `null` (e.g. following a progress reset or card deletion).
    - Added an active ownership check: verifies `this.cardRepo.findUserCardById(metadata.userCardId)` and verifies `userCard.userId === userId`.
    - Also checks if the user possesses any card of `bossElement` in their current collection.
    - If the user does not possess any counter card, `handleTutorialFloor4Defeat` recovers from the stale metadata and grants a real `COMMON` card of `bossElement` from the database.
    - When the card is genuinely owned, returns the verified `userCard` so `floor4Defeat.userCard` is non-null and the `[⚔️ Equip <Card> & Retry]` button correctly displays.
- **TCG User Reset Script (`scripts/reset-tcg-user.ts`)**:
  - Added `tcg_system_configs` cleanup to both SQLite and PostgreSQL transactions:
    - `DELETE FROM tcg_system_configs WHERE key LIKE '%:' || userId`
  - Added `tcg_system_configs` to post-reset verification queries to guarantee complete onboarding state reset.
- **State Repair**:
  - Executed `pnpm tcg:reset-user 1257377848671600722`, deleting 2 stale rows from `tcg_system_configs` (`tutorial:floor4:1257377848671600722` and `tutorial:floor3:potions_reward:1257377848671600722`).
- **Test Coverage (`packages/services/src/waifu-tcg/__tests__/tutorial-floor4-element.test.ts`)**:

## 3. Decisions & Gotchas
- **Self-Healing State**: Even if metadata persists in `tcg_system_configs`, domain services must never rely on flags alone when dealing with asset ownership. Checking the actual card collection prevents players from getting trapped in an uncompletable tutorial state if cards were deleted, transferred, or reset.
