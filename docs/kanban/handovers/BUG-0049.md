## GROOMING · 2026-10-18T12:48:23Z · claude-opus-5-5 (coordinator)

**Docker Scout findings (critical and high only, `ririkoai/ririkobot:2.0.0`)**
- Debian 12 base: perl 5.36.0-7+deb12u3 (4C 5H, fix available), ffmpeg 5.1.9 (1C 21H, no fix in bookworm), tiff 4.5.0 (1C 1H, no fix), util-linux (6H), cjson (3H), mbedtls (2H), openssl, zlib, expat, jpeg-xl, librsvg (1H each).
- npm CLI bundled in the Node image under /usr/local/lib/node_modules/npm: brace-expansion 2.0.2 (5H), pacote 19.0.2 and 20.0.1, sigstore 3.1.0, ip-address 10.1.0, picomatch 4.0.3, http-cache-semantics 4.2.0 (1H each), all with fixes.
- Dashboard image additionally: next 16.3.6, sharp 0.35.4, source-map-js 1.2.1 (1H each, fixes exist; Dependabot #715 bumps next to 16.3.8).

**Approach**
1. Runtime stage: after the apt install, `apt-get upgrade -y` (or move to trixie), then remove `/usr/local/lib/node_modules/npm`, `/usr/local/lib/node_modules/corepack`, and the `npm`, `npx`, `corepack`, `yarn`, `yarnpkg` links in `/usr/local/bin`, and `/opt/yarn-*` if present. The build stages keep them (pnpm comes through corepack there).
2. Try `node:22-trixie-slim` for all stages. Check that `@napi-rs/canvas` and `better-sqlite3` prebuilt binaries load (glibc in trixie is newer, which is fine for prebuilds), that ffmpeg and fonts-dejavu-core and tini exist under the same package names, and that the e2e job passes.
3. Raise the npm packages: `next` to the newest 16.3.x patch, `sharp` and `source-map-js` to fixed versions (pnpm `overrides` in the root package.json for transitive ones). Run `pnpm install` and keep the lockfile change minimal.
4. If Docker can run locally, build both images and scan them with `docker scout cves --only-severity critical,high --only-fixed local://<image>`; otherwise say in the PROGRESS entry that the scan runs after the CI build (the coordinator scans the pushed rc).

**Pitfalls**
- Do not change the user (10001), HOME=/tmp, the healthchecks or the entrypoints.
- The Dockerfile `manifests` stage must keep listing every workspace package.json (apps/starter included).
- A base image change can change ffmpeg behaviour for the built-in player; Lavalink is the main path, but note it.

**Release**: after the merge, tag `v2.0.1-rc.1` to build and scan, then `v2.0.1`, then move `latest` (docs/release.md section 6).

**Out of scope**: production (paused), app features.
