- `pnpm-workspace.yaml`: `onlyBuiltDependencies: [esbuild]` and `ignoredBuiltDependencies: [better-sqlite3, '@google/genai', protobufjs]`, with comments.
- `SETUP.md` section 3.1: one sentence that the first start builds the project (a minute or two). Step order unchanged. README unchanged.

**Why each dependency (deviation from the acceptance text: `better-sqlite3` is NOT in `onlyBuiltDependencies`)**
- `better-sqlite3` (13.0.3): no install script in its package.json, but it has a `binding.gyp`, so pnpm runs an implicit `node-gyp rebuild` when it is allowed. Proven on the fresh clone: allowing it made `pnpm install` fail (`'node-gyp' is not recognized`, ELIFECYCLE exit 1). It ships `prebuilds/` for win32/darwin/linux x64 and arm64 (and musl), so it works without any script. Listed under `ignoredBuiltDependencies` to silence the warning.
- `esbuild`: postinstall validates and optimizes the platform binary used by tsx/vite. Harmless, so allowed.
- `@google/genai`: only script is `preinstall: echo`. Ignored.
- `protobufjs`: postinstall only checks a version scheme and warns. Ignored.
- `@napi-rs/canvas`: no install scripts (prebuilt binaries via optional packages). Not listed.

**Fresh-clone proof** (Windows x64, Node 22.23.2, pnpm 10.8.1, network install, clone of branch under $TEMP, with the edited `package.json` and `pnpm-workspace.yaml` copied in; deleted afterwards)
1. Before the fix: `pnpm install` printed `Ignored build scripts: @google/genai, better-sqlite3, esbuild, protobufjs.`
2. With the fix, after removing every `node_modules`: `pnpm install` finished with no warning and no ignored-scripts box.
3. In `packages/database`: `new (require('better-sqlite3'))(':memory:').prepare('select 1 a').get()` returned `{ a: 1 }`.
4. `pnpm installer --no-open` ran `tsc -b && tsx apps/cli/src/index.ts setup --no-open` and printed `RirikoAI setup (source install). Settings file: …\.env` and `Open this address in your browser: http://127.0.0.1:3999/?token=<masked>`. `curl http://127.0.0.1:3999/` answered 403 without the token. Process stopped, port 3999 free.
5. Not proven: macOS/Linux (no such host), and an offline install.

**verify_cmd**: `pnpm typecheck && pnpm vitest run apps/cli/src && pnpm lint --quiet && pnpm format:check` passed.

**Flag (not ticketed)**: in the clone `pnpm doctor` ran pnpm's own `doctor` command (it reported pnpm 12.4.1), not the repo script. Newer pnpm gives its built-in command priority, so `pnpm run doctor` is the safe form. Docs that say `pnpm doctor` may need that wording; the coordinator decides.
