# Handover Note: [TASK-1402] AutoRole Engine: Join Roles (Humans & Bots), Verification Gateway & Temp Role Sweeper

## 1. Summary of Changes
- **Role System Types**:
  - Created `packages/services/src/roles/types.ts` defining `AutoRoleJoinResult`, `VerificationResult`, `TemporaryRoleResult`, `RoleSweeperResult`, `ReactionRoleType`, `ReactionRoleMode`, `RoleAssignmentResult`.
- **AutoRole Service**:
  - Implemented `AutoRoleService` in `packages/services/src/roles/autorole.service.ts`:
    - `hasManageRolesPermission(guild)`: checks bot's `ManageRoles` permission.
    - `isValidAssignableRole(guild, roleId)`: checks `@everyone`, managed bot roles, and bot role hierarchy vs target role.
    - `canManageMember(guild, member)`: checks bot's highest role vs member's highest role, preventing tampering with guild owners or higher staff.
    - `handleMemberJoin(member)`: assigns human join roles or bot join roles based on member type.
    - `handleVerification(guild, member)`: handles verification gateway button clicks or commands, granting access cleanly.
    - `assignTemporaryRole(guild, member, roleId, durationMs, assignedBy, reason)`: adds role and persists expiry in DB.
    - `removeTemporaryRole(guild, member, roleId)`: revokes role and removes DB record.
    - `sweepExpiredRoles(client)`: background sweeper that revokes expired temporary roles across guilds and cleans up records.
    - `startSweeper(client, intervalMs)` / `stopSweeper()`: managed interval lifecycle with unref.
- **Export**:
  - Exported `AutoRoleService` and role types in `packages/services/src/roles/index.ts` and `packages/services/src/index.ts`.
