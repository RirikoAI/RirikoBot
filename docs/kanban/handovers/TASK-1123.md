## 5. Delivered (2026-09-29)
- `WaifuCardRepository.listUserAlbum(userId, {favoritesOnly?, rarity?, limit, offset})`: one join of `user_cards` → `waifu_cards` (inner, so owned cards whose definition was deleted are skipped) → `waifu_assets` → `waifu_sources` (left), ordered `obtained_at desc, id desc`, plus a matching count. Exported type `UserAlbumEntry`.
- `CardAlbumService`, `parseAlbumQuery`, `ALBUM_PAGE_SIZE` (24), `ALBUM_RARITIES` in `packages/services/src/waifu-tcg/album/`, exported as the canvas-free subpath `@ririko/services/tcg-album`. The `CardImageService` is imported lazily on the first card drawn and memoised; cards draw sequentially; a failed draw yields `image: null` and a warning. Attribution text comes from the asset's source (`getCardAttribution`), `maxCollectionNumber` from `waifuCardRepo.count()`, the same inputs as `/cards`.
- A page past the end falls back to the last page. Invalid filters fall back to defaults.
- Page `apps/web/src/app/account/album/page.tsx` (GET form filters, pagination links, `<img>` data URLs), "Card album" link in the user menu and a "Card Album" tab in `AccountNav`. `cardAlbum` added to `WebServices`.
