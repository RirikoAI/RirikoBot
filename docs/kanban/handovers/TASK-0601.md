## 3. Roadblocks, Gotchas & Decisions Made
- **Base Error Subclassing**: `ExternalApiError` is the standard external service error class in `@ririko/core` rather than `ExternalServiceError`. `AiProviderError` subclasses `ExternalApiError` and explicitly sets `this.externalStatusCode` to satisfy `exactOptionalPropertyTypes: true`.
- **Streaming Failover Invariant**: If a stream fails before emitting any chunks, it can safely fail over to the next candidate provider. However, if tokens have already been yielded to the caller, failover is halted and the error is propagated to avoid corrupting consumer state with disjointed model outputs.
