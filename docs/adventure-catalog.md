# Adventure catalog

The game includes 35 adventures. Run `/adventure` to choose randomly, or type a title, theme or element into its `scenario` option. Search returns up to 25 matches while keeping all 35 stories accessible. Prefix commands accept the IDs below, for example `!adv start the-midnight-bakery`.

The 30 new adventures each have four decisions and at least three different endings. Each has its own location illustration, shared across its branches. The original five retain their four- or five-decision graphs and 15 location illustrations. This catalog contains premises, not solution routes.

## Assets and validation

All 413 decision and ending nodes have an illustration mapping. The catalog contains 292 decision nodes, 121 ending nodes and 1,315 complete paths. Automated traversal checks every path reaches the required decision count; delivery tests complete each new adventure in one illustrated Discord message.

Illustrations were generated with `image_gen.imagegen`. Exact prompts and file names are recorded in the [original manifest](../assets/adventure/manifest.json) and [expansion manifest](../assets/adventure/expansion-manifest.json). Keep `assets/adventure/scenes/` with the deployed bot. See the [runtime guide](adventure-runtime.md) for commands and rollout requirements.
