# Adventure Catalog

There are 35 adventures. Run `/adventure` for a random one. Or type a title, a theme or an element in the `scenario` option to search. The list shows up to 25 results at a time. With the prefix, give the ID, for example `!adv start the-midnight-bakery`.

The first 5 adventures have 4 or 5 decisions. The other 30 have 4 decisions and at least 3 different endings. The tables show only the start of each story. They do not show how to win. For the rules of the game, read [adventure-game.md](adventure-game.md).

## 3. Pictures

Each adventure shows a picture of its place. The files are in `assets/adventure/scenes/`. Keep this folder with the bot. Without a picture, the story still works as text.
